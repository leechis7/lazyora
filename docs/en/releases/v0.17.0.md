LazyOra v0.17.0 supports row insertion and deletion drafts in results with a verified physical ROWID and base table.

- **Alt+Insert** adds a row. Choose the database default, NULL, or an explicit value for each field, then press **Ctrl+S** to stage it. Press Enter on a staged row to edit it again.
- **Alt+Delete** toggles a pending deletion on an existing row or removes a new draft. Existing rows can be deleted only when all original columns can be checked for changes.
- **Alt+C** commits row additions, deletions, and cell edits together; **Alt+R** rolls back. If an original row has changed or a save fails, LazyOra rolls back the attempt and keeps the drafts. Resolve row drafts before exporting.

The shared Tuivory Go v0.12.4 grid marks row states. Oracle Free tests verified conflict detection, recovery and retry after a failed save, and the distinction between defaults and explicit NULL.

AMD64 and ARM64 executables are available for Linux, Windows, and macOS. Verify them against `SHA256SUMS`. On Linux and macOS, grant execute permission with `chmod +x <executable>`.
