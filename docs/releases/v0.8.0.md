LazyOra v0.8.0은 여러 Oracle 접속을 작업 공간으로 나누고, 도움말·테마·터미널 조작을 개선한 기능 릴리스입니다.

## 주요 변경

- **접속별 작업 공간:** Alt+J로 작업 공간을 만들고 전환합니다. Oracle 세션·SQL 탭·조회 결과·트랜잭션을 접속별로 유지하며, 미저장 SQL과 미커밋 가능 내역을 확인한 뒤 닫습니다.
- **내장 도움말:** 도움말 메뉴에 한·영 사용 가이드, 버전 변경 이력, 환경 진단과 GitHub 문제 신고·기능 제안 양식을 추가했습니다. 사용 가이드와 변경 이력은 실행파일에 포함되어 오프라인에서도 볼 수 있습니다. 프로그램 정보는 중앙 팝업으로 표시합니다.
- **공통 UI:** 포커스된 박스는 이중선과 강조색으로 구분합니다. 목록·목차는 방향키로 이동하며, 도움말 상단 목차의 마우스 클릭과 팝업 배경이 비치는 문제를 수정했습니다.
- **테마:** 다크·라이트 외에 흑백(Black / White) 테마를 추가했습니다. 라이트 편집기 배경을 흰색으로 맞추고 8/16색 환경의 팝업·입력·버튼 대비를 개선했습니다.
- **메뉴·전체화면:** F10은 상단 메뉴, Shift+F10은 문맥/소스 편집 메뉴입니다. F2는 SQL, Shift+F2 또는 F12는 결과 전체화면·복원입니다. 전체화면에서 Esc로 분할 화면으로 돌아갑니다. 팝업 닫기와 실행 중 쿼리 취소가 우선합니다.
- **터미널 호환:** Unix에서 TERM이 없거나 비어 있으면 앱 내부에서 ansi를 사용합니다. 구형 기능키 입력을 보완하고 MobaXterm에서 Shift+F2가 일반 F12로 전달되는 경우도 지원합니다. ansi 터미널은 마우스 기능을 선언하지 않으므로 마우스가 필요한 경우 실제 클라이언트에 맞는 xterm 설정을 사용합니다.
- **회귀 검사:** Oracle 버전별 외부 시험 설정, 실제 접속 단절·넓은 결과 보관·내보내기 디스크 부족 검사와 Windows/macOS 모의 UI 검사를 확대했습니다.

## 검증과 지원 범위

Linux ARM64의 Go race 테스트·vet·빌드와 실제 PTY의 도움말·테마·마우스·전체화면·TERM 기본값 검사를 수행합니다. GitHub CI와 Release Actions에서 Linux·Windows·macOS AMD64/ARM64 빌드, Windows 버전 명령과 Windows/macOS 설정·모의 UI·내보내기 검사를 수행합니다. 실DB 검사 기록과 버전별 제한은 [호환성 기록](https://github.com/leechis7/lazyora/blob/v0.8.0/docs/compatibility.md)을 참고하세요.

실제 CentOS 7.4·Oracle 10g와 Windows/macOS의 전체 TUI 재시험은 이번 배포에서 수행하지 않았습니다. PL/SQL 디버거는 조사·설계 문서만 추가했으며 중단점·스텝 실행 기능은 포함하지 않습니다. Tibero 지원도 포함하지 않습니다.

## 다운로드

Linux·Windows·macOS AMD64/ARM64 실행파일 6종과 LICENSE·README.md·TVIEW-LICENSE.txt·SHA256SUMS를 제공합니다. Go나 Oracle Instant Client를 별도로 설치하지 않습니다. Linux·macOS는 `chmod +x`로 실행 권한을 부여하세요.
