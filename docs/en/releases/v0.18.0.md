LazyOra v0.18.0 compares data across two Oracle connections in **Tools → Compare table data**.

- Select a table on each connection and enter common key columns. Composite keys are supported. Results show rows present only on either side and the column values that changed.
- The comparison is limited to 5,000 rows, 64 columns, and approximately 16 MiB per table. NULL or duplicate keys and limit violations produce no partial results. **Esc** cancels both reads.
- Comparison is read-only and preserves existing SQL results and pending work. Reads on the two connections may observe different points in time.

Oracle Free tests covered composite keys, numeric precision and NULL, and preservation of existing cursors and transactions. [Usage guide](https://github.com/leechis7/lazyora/blob/v0.18.0/docs/en/usage.md#compare-table-data-across-two-connections)

AMD64 and ARM64 executables are available for Linux, Windows, and macOS. Verify them against `SHA256SUMS`.
