LazyOra v0.10.2는 공통 UI 스타일을 Tuivory 공개 Go 패키지로 통합한 유지보수 릴리스입니다.

### 주요 변경

- **Tuivory v0.0.1 적용**: 테마·색상 프로필·입력·선택·버튼·표·팝업·그리드·SQL 문법색의 중복 구현을 공통 패키지로 전환했습니다.
- 기존 화면과 Oracle 실행·트랜잭션·SQL 편집·Toad 키맵·결과 복사·미커밋 표시를 유지합니다. 새 사용자 기능이나 단축키 변경은 없습니다.
- 소비 패키지는 `github.com/leechis7/tuivory/go v0.0.1`입니다. 실행에는 별도 Tuivory 설치가 필요 없습니다.

### 검증

- 전체 Go race 테스트·정적 검사·Linux ARM64 로컬 빌드를 통과했습니다.
- 다크/라이트/흑백 × 8/16/256/True Color × 한·영 × 67장면에서 3,216개 모의 화면을 새로 비교했습니다. 무작위 테스트 경로를 제외한 표시 차이와 테마 왕복 차이가 없었습니다.
- GitHub CI와 Release는 Linux·Windows·macOS의 AMD64/ARM64 바이너리를 검사합니다. 실제 원격 단말·사용자 팔레트·실DB 전체 검증과는 구분합니다.

### 다운로드

사용할 OS·아키텍처에 맞는 바이너리 하나를 받으세요. Linux/macOS에서는 실행 권한을 부여하고, 체크섬은 첨부한 `SHA256SUMS`로 확인할 수 있습니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`

CentOS 7.x 등 구형 환경의 지원 범위는 README와 기존 호환성 기록을 참고하세요. 이번 릴리스에서 구형 커널·실제 Oracle 서버 시험을 새로 수행한 것은 아닙니다.
