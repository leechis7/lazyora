LazyOra v0.13.0 adds batch grid editing, connection environment labels, and SQL favorites.

- Press Enter or double-click an editable result cell, then use Tab or Shift+Tab to move between editable cells. Alt+C commits all drafts together and Alt+R discards them. Rerunning asks before discarding drafts, and a failed batch retains them.
- Set a custom environment label, such as `[PROD · Seoul]`, in the connection form. The label is shown on the active connection and when confirming risky SQL or scripts.
- In F8 history, Alt+S saves the selected SQL to favorites and Alt+F opens the list. Find favorites by name or tag and open them in a new tab without executing them. SQL text is stored locally as plain text.
- Tuivory Go v0.12.2 centers popup buttons and distinguishes the active grid cell from the selected range. The eight-color monochrome profile uses the same color for both.

### Verification

The Docker Oracle Free integration suite passed, including batch editing, commit and rollback, ROWID editing, and cursor cancellation.

### Download

Linux AMD64 and ARM64, Windows AMD64 and ARM64, and macOS AMD64 and ARM64 are supported. Download the executable for your OS and architecture and verify it against `SHA256SUMS`. On Linux and macOS, grant execute permission with `chmod +x <executable>`.
