LazyOra v0.12.0 is a feature release adopting published Tuivory Go v0.4.0 menus, configurable result grids and surface styling.

### Changes

- Shared menu bars, nesting/back, separators, disabled presentation and pointer navigation. Preserve F10/Shift+F10/Alt entry, Left/Right top-level navigation and caller-panel restoration.
- Render results through the same common Grid's data preset/options: row numbers, dividers, stripes, numeric alignment, current/range/edited cells and status. **Drag header column dividers to resize**, retaining existing width commands.
- Public PanelView owns menu single borders, titles, backgrounds and wide-glyph protection; remove the separate border workaround. Ordinary focused panels retain double borders.
- Bind ordinary text to its actual surface and show inactive entries in gray/Dim without ordinary prefixes. Block disabled focus/click/activation. Actual eight-color Dim brightness is terminal-dependent.
- Current-row/clipping markers are `>`/`~`. Edited-cell backgrounds/status `*` remain; row-number `*` is omitted. Preserve original values, ROWID mappings, edit confirmations, transactions, copy/export and global shortcuts.
- Refresh bilingual usage/offline guides, README and actual executable demo captures.

### Verification and scope

Passed full local Go race (UI 208.583 s), vet/Linux ARM64 build, 24 language/theme/color combinations and the new 12-palette disabled/surface test. Three isolated actual PTYs (Korean/English Unicode and English ASCII) exercised 24 SIGWINCH resizes across the main screen/open menus, followed by working menu/copy/details/connection/exit operations with unchanged settings. Release-version/embedded-doc/capture checks follow preparation.

GitHub CI/Release runs complete checks and Linux/Windows/macOS AMD64/ARM64 builds. Real remote terminals/fonts/CentOS/other-OS UI/new live Oracle connections are outside these checks. Do not copy the private Tuivory playground resize fix: LazyOra's own app was exercised. Remaining LORA-76 application panel/split/footer work is not completed by this release.
