LazyOra v0.10.1은 테마·색상 수별 공통 스타일과 가독성, 테마 변경 후 상태 복원을 개선한 수정 릴리스입니다.

## 주요 수정

- **색상 프로필:** 다크·라이트·흑백 테마와 ANSI 8/16색·256색·True Color를 구분하고 공통 역할별 전경/배경을 적용했습니다.
- **안내문과 제목:** 마스터 암호·암호 관리의 설명문과 흑백 복사창 제목이 배경에 묻히는 문제를 수정했습니다. 비활성 버튼·메뉴도 읽을 수 있게 했습니다.
- **선택과 문법 강조:** 일부 터미널에서 굵게 속성이 글자색을 밝게 바꿔 대비가 떨어지던 입력·선택·수정 셀 스타일을 정비했습니다. SQL 문법 강조도 출력 능력에 맞춰 표시합니다.
- **테마 복원:** 색상 값을 추측해 바꾸던 방식을 역할 기반 재적용으로 바꿨습니다. 테마를 바꿨다가 돌아와도 탭·상세 표·팝업의 스타일이 복원되며 SQL·입력값·선택·포커스를 유지합니다.
- **미커밋 표시:** 변경 셀의 배경 외에 행 번호 `*`와 선택 셀 상태 문구로 미커밋 변경을 확인합니다. 복사·내보내기 원본 값에는 표식을 넣지 않습니다.
- **개발 문서:** 공통 스타일 가이드, 수정 전후 비교 자료, 향후 독립 TUI 스타일 가이드 프로젝트 준비 문서를 추가했습니다.

## 검증

로컬 전체 Go race 테스트·vet·Linux ARM64 빌드를 통과했습니다. 실제 앱 위젯의 67장면 × 12색상/테마 조합 × 한·영 × 초기/왕복 3,216프레임을 비교해 1,608쌍의 테마 왕복 렌더링 차이가 없음을 확인했습니다. 두 굵게 모델을 적용한 참조 팔레트 분석 범위에서 동일 전경/배경 및 4.5:1 미만 텍스트 후보는 없었습니다. 분석은 Dim 배경·공백·장식선 등을 제외하며 모든 실제 단말의 대비를 보장하지 않습니다.

GitHub CI·Release는 전체 테스트·vet·6종 바이너리 빌드와 Windows 실행파일 및 Windows/macOS 설정 경로·모의 UI 검사를 수행합니다. SecureCRT·MobaXterm의 실제 사용자 팔레트, CentOS 7.4·Oracle 10g 및 Windows/macOS의 전체 실사용 TUI를 이번 변경으로 재시험한 것은 아닙니다.
