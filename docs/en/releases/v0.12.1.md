LazyOra v0.12.1 is a patch adopting published Tuivory Go v0.5.0 popups and source-edit menus while preserving existing behavior.

### Changes

- Replace local popup card/shadow painting with ShadowView/DimRegion. Preserve card sizing with explicit Auto right-one/down-one offsets, reducing them when space is unavailable. Dim retains original background colors.
- Show source-editor Shift+F10 actions in a common MenuView/PanelView popup; retain editing/keymaps/clipboard with arrow/Enter/Esc navigation.
- Traverse public StyleChildren for nested form buttons/open choices, preserving arrow navigation, safe confirmation defaults and caller focus.
- Retire deprecated style/selection-color consumers; update bilingual usage/offline guides and actual executable captures.

### Remaining target

**This does not remove all direct tview imports.** Tuivory's shared design covers current Go/Rust and future Python/JavaScript/C/C++; LazyOra consumes its Go adapter. Complete UI facade/layout/surface/secret-input/editor APIs are requested in TVR-22–26. App/test import-zero and removal of the local editor fork follow published support; broader LORA-76 remains open.

### Verification

Passed full local race (UI 188.771 s), vet/Linux ARM64 build, existing bilingual/twelve-palette/wide-glyph/physical-Show regressions and new shadow input/paste tests. Three isolated actual PTYs (Korean/English Unicode, English ASCII) exercised 33 resizes, normal exit and unchanged settings. Release-version embedded-document checks and Korean/English captures also passed.

GitHub CI/Release runs Linux/Windows/macOS AMD64/ARM64 builds and automated checks. New live Oracle, remote SSH/physical fonts/CentOS/other-OS UI are outside scope. Corrected wrapper traversal and a stale capture version expectation were retested; failed attempts were not counted as passes.
