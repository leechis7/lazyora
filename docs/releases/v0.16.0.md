LazyOra v0.16.0은 **세션 → 세션 브라우저**에서 Oracle 세션과 잠금의 차단·대기 관계를 보여줍니다.

- 조회에는 `GV$SESSION` 접근 권한이 필요합니다. 차단·대기 세션을 우선 표시하고, 최대 500개를 보여줍니다.
- `ALTER SYSTEM` 권한과 대상 계정의 보호 여부가 확인되면 **차단 세션 종료**를 요청할 수 있습니다. 확인창의 기본값은 **취소**입니다. 종료 직전에 대상과 차단 관계를 다시 확인하고 현재 세션, 백그라운드 세션 및 Oracle 관리 계정을 보호합니다. 계정 보호 정보를 제공하지 않는 구형 DB에서는 조회만 가능합니다.
- Oracle은 대상의 미커밋 작업을 롤백합니다. SQL 편집기의 트랜잭션은 별도로 유지됩니다.

Oracle Free에서 실제 행 잠금, 종료 후 대기 재개, 대상 롤백과 편집기 트랜잭션 격리를 확인했습니다. RAC 및 구형 Oracle의 세션 브라우저는 실환경 시험을 하지 않았습니다.

Linux·Windows·macOS용 AMD64·ARM64 실행파일을 제공하며 `SHA256SUMS`로 확인할 수 있습니다. Linux와 macOS에서는 `chmod +x <실행파일>`로 실행 권한을 부여하세요.
