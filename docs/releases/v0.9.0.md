LazyOra v0.9.0은 실제 ROWID가 포함된 단일 테이블 조회 결과의 안전 편집과 그리드 직접 편집을 추가한 기능 릴리스입니다.

## 주요 변경

- **직접 작성한 SELECT 결과 편집:** `SELECT t.ROWID, t.* FROM 테이블 t WHERE ...`를 F9로 실행하면 검증된 원본 컬럼을 수정할 수 있습니다. 직접 컬럼의 별칭·WHERE·ORDER BY·IN 바인드를 유지하며, 추가 페이지와 정렬·필터 후에도 원래 행을 찾아 반영합니다. 적용 후에는 원래 SELECT와 바인드로 재조회합니다.
- **그리드 직접 편집:** 편집 가능한 셀에서 Enter·더블클릭으로 기존 값을 수정하거나 문자 입력으로 교체합니다. Enter로 변경 전·후를 확인하고 승인해야 UPDATE가 실행됩니다. Esc는 입력을 취소하고, 확인창의 취소는 입력 중인 셀로 돌아갑니다. Ctrl+U는 입력 지우기, Alt+Delete는 NULL 지정입니다.
- **별도 편집창 유지:** 편집 메뉴·결과 문맥 메뉴의 ‘별도 창에서 셀 편집’도 사용할 수 있습니다. 편집 가능한 셀의 원문 상세 조회는 문맥 메뉴의 ‘셀 상세’를 사용합니다.
- **변경 셀 표시:** 반영했지만 아직 커밋하지 않은 셀은 노란 계열 배경(흑백 테마는 회색)으로 표시합니다. 실제 ROWID·원본 컬럼명으로 추적하므로 정렬·필터·재조회·SQL 탭 전환에도 유지되며, 커밋·롤백·재접속 후 표시를 해제합니다. 롤백 후 최신 값은 다시 조회하세요.

## 편집 범위와 트랜잭션

실제 ROWID와 원본 컬럼을 확인할 수 있는 일반 영구 heap 테이블의 단일 테이블 조회를 지원합니다. ROWID 자체와 LOB 등 미지원 타입은 읽기 전용입니다. JOIN·뷰·동의어·DB 링크·WITH·서브쿼리·집계·계산식 등 불명확한 결과는 편집하지 않습니다.

값은 바인드로 전달하며, ROWID와 조회된 편집 가능 컬럼의 기존 값을 비교해 충돌을 검사합니다. 조회하지 않은 컬럼·읽기 전용 LOB의 변경까지 감지하는 것은 아닙니다. 다른 세션의 잠금에는 NOWAIT로 대응하고, 실패한 시도는 SAVEPOINT로 되돌려 이전 미커밋 작업을 보존합니다. 변경 확인은 자동 커밋이 아닙니다. **Alt+C 커밋 / Alt+R 롤백**을 별도로 실행하세요. 트리거가 실행되거나 WHERE 조건 변경으로 행이 결과에서 빠질 수 있으므로 재조회 결과를 확인하세요.

## 검증

Linux ARM64에서 전체 Go race 테스트·vet·빌드, 실제 Oracle Free의 직접 ROWID 편집·충돌 검사·추가 페이지·커밋/롤백 통합 검사와 실제 xterm 8색 터미널의 별도 창/직접 편집·확인 취소·셀 배경색·원 SELECT 재조회·롤백 검사를 통과했습니다. GitHub CI에서 Windows/macOS 모의 UI 검사를 수행하고, CI와 Release Actions가 Linux·Windows·macOS AMD64/ARM64 실행파일을 빌드합니다. 실제 CentOS 7.4·Oracle 10g와 Windows/macOS의 전체 TUI 재시험은 이번 배포에서 수행하지 않았습니다.

도움말 키맵 비교표와 VS Code·IntelliJ IDEA 키맵은 후속 백로그이며 이번 릴리스에는 포함하지 않습니다.
