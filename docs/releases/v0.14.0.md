LazyOra v0.14.0은 Oracle 스키마에서 데이터를 탐색하고 두 접속의 테이블 구조를 비교하는 기능을 추가합니다.

- 스키마 트리에서 테이블·뷰·구체화 뷰를 열면 오른쪽에서 컬럼·데이터·DDL 탭을 전환할 수 있습니다. Alt+V로 데이터 미리보기를 열고 Ctrl+N으로 조회 범위를 늘립니다. 기존 SQL 결과와 트랜잭션은 유지됩니다.
- 테이블 데이터에서 행을 선택한 뒤 Alt+F 또는 **관련 행**으로 외래 키를 고르면 부모·자식 행을 별도 읽기 전용 그리드에서 볼 수 있습니다. 복합 키도 지원합니다.
- **도구 → 테이블 구조 비교**에서 열린 Oracle 접속 두 개를 선택합니다. 한쪽에만 있는 테이블과 컬럼의 순서·타입·길이/정밀도·NULL 허용 여부·기본값 차이를 보여줍니다. 접속별로 조회 권한이 있는 메타데이터를 비교합니다.

### 검증

Oracle Free 통합 시험에서 미리보기 중 기존 SQL 커서 보존, 복합 외래 키 양방향 조회, 독립 세션 두 개의 컬럼 길이·기본값 비교와 미커밋 트랜잭션 보존을 확인했습니다.

### 다운로드

Linux·Windows·macOS용 AMD64·ARM64 실행파일 중 환경에 맞는 파일을 받고 `SHA256SUMS`로 확인하세요. Linux와 macOS에서는 `chmod +x <실행파일>`로 실행 권한을 부여하세요.
