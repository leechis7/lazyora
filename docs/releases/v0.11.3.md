LazyOra v0.11.3은 스키마 트리 표시와 컴포넌트 책임 문서를 정리한 패치 릴리스입니다.

### 변경

- 컬럼 앞의 중복 아이콘을 제거합니다. Unicode는 `· · ID` → `· ID`, ASCII는 `. C ID` → `. ID`로 표시해 각 줄의 두 칸을 이름·자료형에 돌려줍니다.
- 공개 Tuivory Go v0.2.0의 기본 말단 표시·들여쓰기·탐색·컬럼 식별·상세 열기는 유지합니다. 공통 렌더러를 수정하거나 복사하지 않았습니다.
- Tuivory는 재사용 컴포넌트를 제공하고 LazyOra는 실제 화면 조합·배치·전역 단축키·기능 연결을 담당한다는 책임 경계를 한영 문서에 정리했습니다. 기존 화면 조합 코드를 전부 라이브러리로 옮기지 않습니다.
- 한영 README 캡처를 현재 실행파일의 데모 화면으로 갱신했습니다. 그리드 옵션/프리셋(TVR-17)은 요청 상태이며 이번 릴리스의 구현 기능이 아닙니다.

### 검증과 범위

기존 트리 펼침/지연 응답/필터·캐시/테마·문자 폭/대량 탐색/부모 객체 동작 검사와 전체 Go race·정적 검사·Linux ARM64 빌드를 확인했습니다. 한영 데모는 DB 없는 실제 실행파일의 PTY 출력이며 실제 DB 결과가 아닙니다.

GitHub CI·Release는 Linux/Windows/macOS AMD64/ARM64 빌드와 자동 검사를 수행합니다. 실제 원격 단말·폰트·CentOS·신규 실DB 접속 검증은 이번 범위와 구분합니다.

### 다운로드

OS·CPU에 맞는 실행파일 하나를 선택하고 `SHA256SUMS`를 확인하세요. Linux/macOS에서는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`
