# 사용 가이드

## 처음 접속하고 조회하기

시작하면 접속창이 열립니다. Alt+L로 다시 열 수 있습니다.
별칭, 호스트, 포트, 계정, 비밀번호, Service Name 또는 SID를 입력하고 접속을 선택하세요.
밝은 입력칸은 직접 입력하고, ▾가 있는 선택칸은 방향키·Enter 또는 마우스로 고릅니다.

SQL 편집기에서 다음 문장을 입력하고 F9 또는 Ctrl+Enter로 실행합니다.

```sql
SELECT sysdate AS server_time FROM dual;
```

Enter는 줄바꿈입니다. 터미널에서 Ctrl+Enter가 전달되지 않으면 F9 또는 Alt+Enter를 사용하세요.
F1 단축키 도움말은 현재 화면과 편집기 키맵에 맞는 조작을 안내합니다.
목차는 ↑/↓ 선택, → 또는 Enter 본문 이동, ← 목차 복귀를 지원합니다.
F10으로 상단 메뉴를 열고 닫습니다. Shift+F10 또는 우클릭으로 현재 창의 문맥 메뉴를 엽니다.
메뉴는 ↑/↓·Home/End·PgUp/PgDn으로 이동하고 Enter로 실행/하위 메뉴를 엽니다. 비활성 항목은 건너뜁니다. ←/Esc는 부모로, 최상위 Esc는 원래 창으로 돌아가며 →는 다음 상위 메뉴입니다.
v0.12.0은 Tuivory v0.4.0의 메뉴 단일선·실제 표면 텍스트와 비활성 회색/Dim 표시를 사용합니다. 비활성 항목은 선택·실행되지 않습니다. 8색 Dim의 밝기는 단말에 따라 다릅니다.
Tab으로 박스를 이동하면 포커스된 박스가 이중선과 강조색으로 표시됩니다.
F2는 SQL 편집기, Shift+F2 또는 F12는 결과창 전체화면입니다. 같은 키 또는 Esc로 분할 화면으로 돌아갑니다.
열린 팝업은 Esc로 먼저 닫고, 쿼리 실행 중에는 실행을 먼저 취소합니다.

## SQL 파일·탭·편집기

Ctrl+N 새 탭, Ctrl+O 파일 열기, Ctrl+S 저장. 다른 이름으로 저장은 파일 메뉴를 사용하세요.
탭 제목의 *는 파일에 저장하지 않은 SQL입니다. 파일 저장은 DB 커밋과 별개입니다.
F9는 선택 영역을 실행하고, 선택이 없으면 커서가 있는 문장을 실행합니다.
F5는 스크립트를 순서대로 실행하며 첫 오류나 취소에서 중단합니다.
PL/SQL 블록 사이에는 별도 줄에 /를 놓습니다. SQL*Plus 명령은 지원하지 않습니다.

공통 테마·입력·선택·버튼·그리드·문법색은 v0.10.2부터 Tuivory 패키지로 통합했습니다. 실행파일에 포함되므로 별도 설치가 필요 없습니다. 다크·라이트·흑백 테마와 단말의 8/16/256색·True Color 프로필을 구분합니다.

도구 → 설정에서 Toad(기본)·Vim·Notepad++·VS Code·IntelliJ IDEA 키맵, 한국어·영어, 다크·라이트·흑백 테마와 마우스를 선택합니다.
도움말 → 편집기 키맵 비교표 또는 F1에서 Alt+K로 키를 비교합니다. 방향키로 셀을 선택하면 아래에 전체 내용이 표시됩니다. Enter로 표/상세를 전환하고 상세에서 방향키·PgUp/PgDn으로 스크롤합니다. Tab은 표·상세·닫기 버튼을 순환합니다. Ctrl+C 복사·Esc 복귀를 사용합니다.
Ctrl+T 자동완성, Ctrl+Shift+F 정렬 등은 F1 → 편집기 키맵에서 현재 매핑을 확인하세요.

## 커밋·롤백·종료

DML 변경은 같은 접속의 탭들이 공유하며 수동 커밋합니다.
Alt+C 커밋, Alt+R 롤백. 세션 → 미커밋 내역 보기에서 실행한 SQL을 확인합니다.
내역은 행별 변경 비교가 아니라 이번 실행의 메모리 기록입니다.

Oracle DDL과 PL/SQL 내부 COMMIT은 DB에서 암시적·명시적 커밋을 일으킬 수 있습니다.
위험한 SQL 확인창의 기본 선택은 취소입니다. SQL을 확인한 뒤 실행하세요.
Ctrl+Q 종료 시 미저장 파일과 미커밋 변경을 각각 확인합니다. Esc는 종료를 취소합니다.
반영 결과가 불확실한 연결은 성공으로 간주하지 말고 새 접속에서 실제 DB 결과를 확인해야 합니다.

## 여러 접속과 스키마 탐색

v0.11.2은 Tuivory **v0.2.0** 공개 트리를 사용합니다. 사용자·객체 유형 선택과 실시간 검색은 유지하며, 테이블·뷰에서 **→/Space 또는 펼침 화살표 클릭**으로 컬럼·자료형을 불러옵니다. **←**는 접거나 부모로 이동하고, **Alt+←/→**는 긴 이름을 가로 이동합니다. **Enter 또는 이름 클릭**은 기존 객체 상세를 엽니다. 컬럼은 펼칠 때 조회해 현재 목록에서 재사용하며, Ctrl+R 새로고침·사용자 변경·재접속 시 캐시를 비웁니다. 실패·취소 후에는 접었다 다시 펼쳐 재시도합니다. 조회 중에는 기존 실행 취소(Esc)와 작업 보호 규칙이 적용됩니다.

Alt+J로 접속 작업 공간을 열고 N 새 접속, Enter 전환, Delete 개별 닫기를 선택합니다.
SQL 탭·조회 결과·트랜잭션은 접속별로 분리됩니다. 운영·개발·시험 환경 표시와 계정·DB를 확인하세요.
한 작업 공간을 닫을 때 다른 접속의 트랜잭션은 유지됩니다.

왼쪽에서 사용자와 객체 종류를 고릅니다. Alt+U 사용자, Alt+O 종류, Alt+B 탐색기 표시·숨김.
Alt+I 객체 검색에 입력하면 현재 사용자·종류에서 객체명과 부분 일치하는 항목만 즉시 표시합니다. ↓/Enter는 목록으로, Esc는 검색 지우기입니다.
Enter로 테이블·뷰 컬럼, 객체 상세를 열고 F4로 커서 위치 객체를 조회합니다.
소스 화면의 적용·컴파일은 DDL입니다. 읽기 전용 조회와 구분하여 사용하세요.
실행 → 프로시저·함수 실행에서 인자를 확인하고 실행할 수 있습니다. 스텝 디버거는 아직 지원하지 않습니다.

## 결과 조회·복사·셀 보기

F6으로 SQL과 결과 사이를 이동합니다. Alt+F8 또는 보기 메뉴로 패널 크기 조절을 열고 ↑↓로 SQL 높이, ←→로 스키마 너비를 조절합니다. Home 초기화, Enter/Esc 종료이며 분할선 마우스 드래그도 가능합니다. 결과 창에서 방향키·PgUp/PgDn으로 탐색합니다.
헤더의 컬럼 구분선을 드래그해 열 너비를 조절할 수 있습니다. 현재 행은 `>`, 편집 셀은 별도 배경과 상태줄 `*`, 공통 폭 생략은 `~`로 표시합니다.
셀 클릭, 드래그 또는 Shift+방향키로 범위를 고르고 Ctrl+C 복사, Alt+Y 행 복사를 사용합니다.
보기/Shift+F10 메뉴에서 다음 1,000행, 정렬·필터·컬럼 너비를 선택합니다.
화면 보관은 F9 조회 하나당 최대 10,000행·추정 64 MiB이며 전체 DB 결과와 다릅니다.

읽기 전용 셀에서 Enter 또는 문맥 메뉴의 셀 상세로 긴 값·NULL·BLOB을 확인하고 개별 원본 파일로 저장합니다.
스키마에서 편집용 테이블을 열거나, 실제 ROWID가 포함된 단일 테이블 SELECT를 F9로 실행하면 셀을 편집할 수 있습니다.
직접 작성한 `SELECT t.ROWID, t.* FROM 테이블 t WHERE ...`도 F9 실행 후 원본 컬럼을 편집할 수 있습니다. 검증된 실제 ROWID는 그리드에서 숨기고 내부 식별용으로 유지하며 변경은 별도 커밋·롤백합니다. JOIN·계산식 등 불명확한 결과는 읽기 전용입니다.
편집 가능한 셀은 Enter·더블클릭으로 직접 수정하거나 문자 입력으로 교체합니다. Enter 변경 확인, Esc 입력 취소, Ctrl+U 지우기, Alt+Delete NULL. Alt+D로 별도 편집창을 엽니다. 변경 확인의 기본 버튼은 진행이며 취소하면 초안으로 돌아갑니다. 반영된 셀은 커밋·롤백까지 다른 배경색으로 표시합니다. 커밋·롤백 성공 후 현재 결과를 원 SQL·바인드로 자동 재조회하며 정렬·필터·열 너비를 유지합니다. 재조회 실패는 트랜잭션 성공과 구분해 표시합니다.
복사가 PC에 도착하지 않으면 편집 → 복사 내용 보기에서 터미널의 선택·복사를 사용하세요.

## 결과 내보내기·실행 계획·출력

Alt+W로 CSV·TSV·Excel(XLSX)·INSERT SQL을 저장합니다.
가져온 결과와 DB 전체 결과(재조회)를 구분하세요. 전체 저장은 원래 SELECT와 당시 바인드를 재실행합니다.
재조회 시 데이터가 달라질 수 있습니다. 진행 중 Esc로 취소할 수 있고 실패·취소 시 기존 파일을 보존합니다.
INSERT 내보내기는 SQL 파일만 만들며 DB에서 실행하지 않습니다.

Ctrl+E로 예상 실행 계획을 보고, Alt+P로 DBMS_OUTPUT을 엽니다.
출력을 먼저 켠 뒤 F9/F5로 실행하세요. 출력은 문장이 끝난 뒤 수집하며 실시간 출력은 아닙니다.

## 접속 저장·마스터 암호

접속창의 저장은 별칭·접속 정보를 저장합니다. 비밀번호는 기본 미저장입니다.
암호화 저장을 선택하려면 8자 이상 마스터 암호를 사용합니다. 도구 → 암호 관리에서 잠금 등을 관리합니다.
마스터 암호를 잊어도 DB 비밀번호를 직접 입력해 접속할 수 있습니다.
마스터 암호를 복구할 수는 없으며 암호 저장소 초기화는 저장한 DB 비밀번호를 지웁니다.

## 터미널 문제와 지원 요청

SecureCRT는 Xterm 에뮬레이션을 확인하세요. TERM이 없으면 ANSI로 실행합니다. TERM=ansi는 마우스를 지원하지 않습니다. 8색과 마우스를 함께 시험하려면 TERM=xterm TCELL_TRUECOLOR=disable을 사용하세요. 도움말 → 환경 진단에서 지원 여부를 확인합니다.
Ctrl+Enter가 일반 Enter로 전달되면 F9/Alt+Enter를 사용하거나 터미널의 키 매핑을 설정합니다.
OSC 52 복사는 터미널·SSH 구성과 클립보드 권한에 따라 수신 여부가 달라집니다.

도움말 → 진단 정보 보기·복사에서 공개 환경 정보를 확인하고 복사할 수 있습니다.
도움말 → 문제 신고·기능 제안에서 주소와 양식을 제공합니다. 실제 암호·접속 정보·SQL·결과는 제거하세요.
버전 변경 이력에는 미배포 개발 내용이 별도로 표시되며, 앱 정보는 도움말 메뉴 마지막에 있습니다.

도구 → 설정의 문자 표시(Alt+D)는 자동/Unicode/ASCII를 저장합니다(v0.11.2). 실행 옵션 --display-mode ascii는 이번 실행만 우선 적용합니다. ASCII는 영어 UI를 사용하고 표시 불가능한 데이터 문자는 ?로 보이지만 SQL·DB 값·앱 복사/내보내기 원문과 한국어 선호를 바꾸지 않습니다. 설정 하단/환경 진단에서 적용 모드·이유를 확인하세요. 실제 폰트 지원은 자동 감지할 수 없습니다.
