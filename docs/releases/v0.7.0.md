LazyOra v0.7.0은 Oracle 개발·조회 흐름을 확장하고, 편집기·결과 그리드·대화상자의 디자인과 테마를 정리한 기능 릴리스입니다.

## 주요 변경

- **다크·라이트 테마:** 설정의 테마(Alt+T)를 선택하고 저장하면 열린 화면과 SQL 탭에 즉시 반영합니다. SQL·PL/SQL 편집기 배경과 문법 강조도 함께 전환하며, 기존 설정은 다크를 사용합니다.
- **일관된 대화상자:** 접속·설정·검색·바인드·내보내기·파일 선택·암호 관리 등을 중앙 팝업과 여유 있는 간격으로 정리했습니다. 입력·선택·버튼 포커스를 구분하고 작은 화면에서 배치를 조절합니다.
- **편집 기능:** 기본·Vim·Notepad++ 키맵, Ctrl+T 객체·컬럼 자동완성, Ctrl+Shift+F SQL·PL/SQL 정렬을 제공합니다. Vim은 지원하는 일부 명령을 구현하며 전체 Vim 호환은 아닙니다.
- **PL/SQL 실행:** DBMS_OUTPUT 창(Alt+P), 메타데이터 기반 함수·프로시저·패키지 멤버 실행, IN/OUT/IN OUT·함수 반환값·기본값·REF CURSOR 결과를 제공합니다.
- **객체 정보:** DDL·제약조건·인덱스와 객체·컬럼 권한, 의존·피의존 관계를 조회하고 관련 객체로 이동할 수 있습니다. 조회 범위는 접속 계정의 권한에 따릅니다.
- **결과 탐색:** F9 SELECT 결과를 같은 커서에서 1,000행씩 추가 조회하고, 가져온 행을 정렬·필터합니다. 화면 보관 상한이 있으며, DB 전체 재조회 내보내기와 범위를 구분합니다.
- **결과 그리드:** 헤더·행 번호·컬럼 구분선·여백·숫자 정렬·현재 행·범위 선택·상태 표시를 개선했습니다. 원본 값 복사·내보내기는 표시 장식과 분리합니다.
- **대형 셀:** Enter·더블 클릭으로 셀 상세를 열고 원문을 복사·저장합니다. LOB은 제한된 미리보기와 추가 읽기, 전체 스트림 파일 저장을 지원합니다.
- **안전한 셀 편집:** 스키마에서 명시적으로 연 일반 테이블의 지원 컬럼을 편집합니다. 변경 검토·동시성 검사·바인드 UPDATE 후 수동 커밋·롤백하며, 일반 SELECT·JOIN·집계·뷰는 읽기 전용입니다.
- **도움말:** 주제별 목차와 키 그룹별 설명을 정리하고, 도움말(H) 메뉴에 프로그램 정보를 추가했습니다.
- **시험 환경:** Oracle 시험 스크립트는 DB를 자동 기동하고, 직접 실행 종료 시 DB를 내릴지 확인합니다. 자동 시험은 종료 시 컨테이너를 정리하며 데이터 볼륨은 보존합니다.

## 검증과 범위

Linux ARM64에서 전체 Go race 테스트·vet·빌드를 통과했습니다. Oracle Free 실제 PTY 시험에서 SQL·바인드·루틴·내보내기·재접속·미커밋 보호·LOB 저장·셀 편집·롤백과 라이트 전환·설정 저장을 검증했습니다. 작은 화면·한글·선택 영역·SQL 원문 보존과 8/16색 대응도 자동 검사했습니다. GitHub CI는 Linux·Windows·macOS AMD64/ARM64 빌드, Windows 버전 실행과 Windows/macOS 설정 경로를 검사합니다.

실제 CentOS 7.4·Oracle 10g 및 Windows/macOS의 TUI 전체 재시험은 이번 릴리스에서 수행하지 않았습니다. 여러 DB 동시 작업 공간, PL/SQL 디버거와 Tibero는 이번 릴리스에 포함되지 않습니다.

## 다운로드

Linux·Windows·macOS AMD64/ARM64 실행파일 6종과 LICENSE·README.md·TVIEW-LICENSE.txt·SHA256SUMS를 제공합니다. Go나 Oracle Instant Client를 별도로 설치하지 않습니다. Linux·macOS는 `chmod +x`로 실행 권한을 부여하세요.
