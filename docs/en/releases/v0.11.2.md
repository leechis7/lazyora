LazyOra v0.11.2 consolidates shared UI handling in public Tuivory APIs.

### Changes

- Adopt **Tuivory Go v0.2.0** and public `WideSafeScreen` for the entire popup draw, removing duplicate local `popupFill` repair for Korean/CJK/emoji overlaps.
- Use public `CellText` for clipped form/button labels, with the common `~` marker.
- Bridge new `Put` writing APIs to the product ASCII adapter, preserving original SQL/results/application copy/export and language preferences.
- Document the Tuivory-first shared UI policy in Korean/English. Full panel/split/footer redesign and replacement form/menu/grid state models are outside this patch.

### Verification and scope

Full UI/race tests, static checks and local Linux ARM64 builds passed. Retain 1,728 physical popup frames and 144 simulated ASCII scenes; verify both wrapper orders, character widths, combining marks and originals. Unicode/ASCII local PTY demo key scenarios exited normally without changing preferences.

GitHub CI/Release runs supported Linux/Windows/macOS AMD64/ARM64 builds and automated checks. Fresh remote customer-terminal/font/CentOS/live-DB verification remains separate. No upstream source was copied or Tuivory project modified.

### Downloads

Choose one executable for your OS/CPU and verify `SHA256SUMS`. Make Linux/macOS binaries executable.
