LazyOra v0.18.0은 **도구 → 테이블 데이터 비교**에서 두 Oracle 접속의 데이터를 비교합니다.

- 각 접속의 테이블과 공통 키 컬럼을 지정합니다. 복합 키를 지원하며, 한쪽에만 있는 행과 값이 바뀐 컬럼을 확인할 수 있습니다.
- 테이블당 5,000행·64컬럼·약 16 MiB까지 비교합니다. 키에 NULL 또는 중복이 있거나 한도를 넘으면 일부 결과를 표시하지 않습니다. **Esc**는 두 조회를 취소합니다.
- 비교는 읽기 전용이며 기존 SQL 결과와 미커밋 작업을 유지합니다. 접속별 조회 시점은 다를 수 있습니다.

Oracle Free에서 복합 키, 숫자 정밀도와 NULL, 기존 조회 커서와 트랜잭션 보존을 검증했습니다. [사용 안내](https://github.com/leechis7/lazyora/blob/v0.18.0/docs/usage.md#두-접속의-테이블-데이터-비교)

Linux·Windows·macOS용 AMD64·ARM64 실행파일을 제공하며 `SHA256SUMS`로 확인할 수 있습니다.
