LazyOra v0.15.0 adds Oracle actual execution plans and collapsible schema and results panes.

- **Execute → Execute and capture actual plan** runs one statement and shows the verified SQL ID and child cursor. When Oracle collects them, step details show actual rows, starts, buffers, disk reads, and elapsed time. Permission or cache failures do not rerun the statement.
- Plan capture uses a dedicated cursor, whose plan may differ from normal execution. Paged results show statistics from the initial fetch. Ctrl+E still displays the estimated plan.
- Click a divider or press **Alt+F7** (schema) or **Alt+F9** (results) to collapse the pane and restore its previous size. Dragging still resizes.

Oracle Free tests verified actual plans, paging, and rollback. Panel tests covered mouse and keyboard controls and state preservation when leaving fullscreen.

AMD64 and ARM64 executables are available for Linux, Windows, and macOS. Verify them against `SHA256SUMS`. On Linux and macOS, grant execute permission with `chmod +x <executable>`.
