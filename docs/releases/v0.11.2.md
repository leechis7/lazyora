LazyOra v0.11.2는 공통 UI 처리를 Tuivory 공개 패키지에 통합한 패치 릴리스입니다.

### 변경

- **Tuivory Go v0.2.0 적용**: 팝업 전체의 한글·CJK·이모지 겹침 처리를 공개 `WideSafeScreen`으로 위임하고 LazyOra의 중복 `popupFill`을 제거했습니다.
- 폼·버튼 등의 폭 제한 라벨도 공개 `CellText`를 사용하며 생략 표식은 `~`입니다.
- 새 `Put` 계열 API에서도 ASCII 표시가 유지되도록 제품 어댑터를 연결했습니다. SQL·결과·복사/내보내기 원문과 언어 선호는 유지합니다.
- 공통 UI는 Tuivory API를 우선 사용하도록 개발 규칙과 한영 문서를 갱신했습니다. 패널·분할·하단 전체 재구성과 새 폼/메뉴/그리드 모델 전환은 이번 배포에 포함하지 않습니다.

### 검증과 범위

전체 UI·race 검사, 정적 검사와 Linux ARM64 빌드를 통과했습니다. 기존 팝업 1,728개 물리 출력 프레임, ASCII 144종 모의 화면, 양쪽 어댑터 순서의 문자 폭·조합 문자·원문 보존을 확인했습니다. 실제 로컬 PTY에서 Unicode/ASCII 데모 키 시나리오가 정상 종료하고 설정 파일을 유지했습니다.

GitHub CI·Release는 Linux/Windows/macOS AMD64/ARM64 지원 빌드와 자동 검사를 수행합니다. 실제 원격 고객 단말·폰트·CentOS·신규 실DB 시험은 이번 범위와 구분합니다. 공개 모듈 소스를 복사하거나 Tuivory 프로젝트를 수정하지 않았습니다.

### 다운로드

OS·CPU에 맞는 실행파일 하나와 `SHA256SUMS`를 받으세요. Linux/macOS에서는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`
