# LazyOra v0.10.2

[한국어](../../releases/v0.10.2.md) | **English**

This is the English description of the existing v0.10.2 maintenance release. It does not add new functionality or replace its published binaries.

## Changes

- **Tuivory v0.0.1** now provides common themes, color profiles, input/choice/button/table/popup styles, result-grid states and SQL syntax colors. Duplicate style implementation was replaced by the public Go package.
- Existing Oracle execution/transactions, SQL editing, Toad keymaps, result copying and uncommitted-edit markers are preserved. There are no new user features or shortcut changes in this release.
- The dependency is `github.com/leechis7/tuivory/go v0.0.1`; running a release binary requires no separate Tuivory installation.

## Verification and downloads

Local full race/vet and Linux ARM64 build passed. The 12-profile comparison generated 3,216 simulated frames across three themes, four color capabilities, two languages, 67 scenes and fresh/roundtrip states. Display and theme-roundtrip comparisons were unchanged after excluding random test-directory text.

Release/main CI passed six-target Linux/Windows/macOS builds and the corresponding automated checks. Actual remote clients, customized palettes, old kernels and every Oracle version were not freshly certified by this release. Earlier CentOS/Oracle test records retain their original scope.

Download the executable matching your system from [the v0.10.2 release](https://github.com/leechis7/lazyora/releases/tag/v0.10.2):

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`.
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`.
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`.

Use executable permissions on Linux/macOS and the provided SHA256SUMS to check downloads. The published assets were verified, including downloaded ARM64 version and Tuivory module information. See [integration](../tuivory-sync.md), [compatibility](../compatibility.md) and the [versioned changelog](https://github.com/leechis7/lazyora/blob/v0.10.2/CHANGELOG.md).
