LazyOra v0.11.0은 스키마 트리 탐색과 터미널 문자 호환 모드를 추가한 기능 릴리스입니다.

### 주요 변경

- **스키마 트리**: 공개 Tuivory Go v0.1.0을 적용했습니다. 테이블·뷰에서 →/Space 또는 펼침 화살표로 컬럼·자료형을 지연 조회합니다. ←는 접기/부모 이동, Alt+←/→는 가로 탐색입니다. 사용자·유형 선택, 실시간 검색, Enter/이름 클릭 상세 보기는 유지합니다.
- **자동/Unicode/ASCII 표시**: 도구 → 설정 → 문자 표시(Alt+D)에서 저장합니다. `--display-mode auto|unicode|ascii`는 이번 실행에만 우선 적용합니다. 자동 모드는 출력 문자 지원을 추정하며, 필요한 문자를 지원하지 않으면 ASCII/영어 UI로 대체합니다.
- SQL·DB 값·앱 복사/내보내기 원문과 한국어 언어 선호를 보존합니다. ASCII 화면의 `?`는 표시 대체 문자입니다. 실제 폰트 지원은 자동 감지할 수 없으며 마우스·색상 지원과 문자 모드는 별개입니다.
- 한국어·영어 README, 사용 가이드, 터미널 안내와 Tuivory 적용 기록을 현행화했습니다. 실행파일에 패키지를 포함하므로 별도 설치는 필요 없습니다.

### 검증 및 범위

전체 Go race 테스트·정적 검사·Linux ARM64 빌드, 12개 테마/색상 조합의 트리 검사, ASCII 144종 모의 화면과 3종 로컬 PTY 시험을 통과했습니다. GitHub CI·Release에서는 Linux·Windows·macOS AMD64/ARM64 빌드와 해당 자동 검사를 수행합니다. 실제 원격 SecureCRT/MobaXterm, 구형 CentOS 및 실DB 접속 시험을 이번 릴리스에서 새로 수행한 것은 아닙니다.

### 다운로드

OS·아키텍처에 맞는 실행파일 하나를 선택하고 `SHA256SUMS`를 확인하세요. Linux/macOS에서는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`

### English summary

LazyOra v0.11.0 adds a Tuivory v0.1.0 schema tree with lazy table/view columns and horizontal panning, plus saved Auto/Unicode/ASCII display modes and a one-run `--display-mode` override. Original SQL/data/application copy/export and language preferences are preserved. Font coverage cannot be detected reliably. See the [English release notes](https://github.com/leechis7/lazyora/blob/v0.11.0/docs/en/releases/v0.11.0.md) for controls, verification scope and downloads.
