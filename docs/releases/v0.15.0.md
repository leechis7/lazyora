LazyOra v0.15.0은 Oracle 실제 실행 계획 수집과 스키마·결과 창 접기·복원을 추가합니다.

- **실행 → 실행 후 실제 계획 수집**에서 SQL 한 문장을 실행하고 SQL ID와 자식 커서로 확인한 실제 계획을 엽니다. Oracle이 수집한 경우 실제 행 수, 시작 횟수, 버퍼 접근, 디스크 읽기, 소요 시간을 볼 수 있습니다. 권한 또는 캐시 문제로 계획을 읽지 못해도 SQL을 다시 실행하지 않습니다.
- 실제 계획 수집은 전용 커서를 사용합니다. 일반 실행과 실행 계획이 달라질 수 있으며, 여러 페이지인 결과는 최초 조회 시점의 통계를 표시합니다. Ctrl+E는 기존 예상 계획을 표시합니다.
- 분할선을 클릭하거나 **Alt+F7**(스키마), **Alt+F9**(결과)로 창을 접고 이전 크기로 펼칠 수 있습니다. 드래그는 크기 조절에 사용합니다.

Oracle Free에서 실제 계획, 결과 페이징, 롤백을 검증했고, 패널 테스트로 마우스·키보드 조작과 전체화면 복귀 시 상태 보존을 확인했습니다.

Linux·Windows·macOS용 AMD64·ARM64 실행파일을 제공하며 `SHA256SUMS`로 확인할 수 있습니다. Linux와 macOS에서는 `chmod +x <실행파일>`로 실행 권한을 부여하세요.
