LazyOra v0.17.0은 실제 ROWID와 원본 테이블이 확인된 결과에 행 추가·삭제 초안을 지원합니다.

- **Alt+Insert**로 행을 추가합니다. 컬럼마다 DB 기본값, NULL 또는 직접 입력을 선택하고 **Ctrl+S**로 초안을 저장합니다. 추가한 행을 선택하고 Enter로 다시 편집할 수 있습니다.
- **Alt+Delete**는 기존 행의 삭제 예약을 켜거나 끄고, 새 행에서는 초안을 제거합니다. 원본 컬럼을 모두 비교할 수 있을 때만 기존 행을 삭제할 수 있습니다.
- **Alt+C**로 행 추가·삭제와 셀 수정을 함께 커밋하고 **Alt+R**로 롤백합니다. 저장 시 원본 행이 바뀌었거나 중간에 오류가 발생하면 해당 저장을 되돌리고 초안을 유지합니다. 행 초안을 정리한 뒤 결과를 내보낼 수 있습니다.

Tuivory Go v0.12.4의 공통 그리드가 행 상태를 표시합니다. Oracle Free에서 충돌 감지, 실패 후 복구와 재시도, 기본값과 명시적 NULL을 검증했습니다.

Linux·Windows·macOS용 AMD64·ARM64 실행파일을 제공하며 `SHA256SUMS`로 확인할 수 있습니다. Linux와 macOS에서는 `chmod +x <실행파일>`로 실행 권한을 부여하세요.
