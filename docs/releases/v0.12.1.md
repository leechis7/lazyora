LazyOra v0.12.1은 Tuivory Go v0.5.0의 공통 팝업·소스 편집 명령 메뉴를 적용하고 기존 동작을 보존한 패치 릴리스입니다.

### 변경

- 팝업의 직접 카드·그림자 셀 그리기를 제거하고 공개 ShadowView/DimRegion에 위임합니다. 기존 카드 크기를 유지해 Auto 그림자는 오른쪽/아래 1칸으로 지정하며 공간이 없으면 줄입니다. 원래 배경색은 Dim으로 감쇠합니다.
- 소스 편집기의 Shift+F10 명령을 공통 MenuView/PanelView 팝업으로 표시합니다. 편집·키맵·클립보드 동작은 유지하고 방향키/Enter/Esc로 조작합니다.
- 공개 StyleChildren으로 래퍼 안의 폼 버튼·열린 선택 상자를 탐색해 좌우 이동·안전한 확인 기본값·포커스 복귀를 유지합니다.
- 폐기 예정 스타일/선택색 API를 권장 API로 바꾸고 한영 안내·내장 가이드·실제 실행파일 캡처를 갱신했습니다.

### 남은 목표

**tview 직접 import가 전부 제거된 릴리스는 아닙니다.** Tuivory는 Go/Rust와 향후 Python·JavaScript·C·C++를 고려한 언어 중립 SDK이며, LazyOra는 Go 패키지를 소비합니다. 전체 UI 파사드·배치·표면·보안 입력/편집기 API는 TVR-22~26으로 요청한 선행 범위입니다. 앱/테스트의 직접 import 0개와 로컬 편집기 포크 제거는 해당 공개 API 제공 뒤 진행합니다. LORA-76 전체를 완료하지 않습니다.

### 검증

전체 로컬 race(UI 188.771초), 정적 분석·Linux ARM64 빌드, 기존 한영/12팔레트/한글 경계·물리 Show 출력 회귀와 새 그림자 입력/붙여넣기 검사를 통과했습니다. 실제 격리 한글/영어 Unicode·영어 ASCII PTY에서 33회 크기 변경 후 정상 종료·설정 보존을 확인했습니다. 릴리스 버전의 내장 문서와 한영 캡처도 확인했습니다.

GitHub CI/Release는 Linux·Windows·macOS AMD64/ARM64 빌드와 자동 검사를 수행합니다. 실DB 신규 접속·원격 SSH/물리 폰트·CentOS·다른 OS 실제 UI 시험은 이 검증과 구분합니다. 실패했던 래퍼 탐색과 낡은 캡처 버전 기대값은 수정 후 재검증했으며 실패한 시도를 통과로 계산하지 않았습니다.

### 다운로드

OS·CPU에 맞는 실행파일 하나와 SHA256SUMS를 확인하세요. Linux/macOS는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`
