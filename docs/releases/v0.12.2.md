LazyOra v0.12.2는 Tuivory Go v0.10.1을 적용하고 메뉴 위치·팝업·저색상 가독성을 개선한 패치 릴리스입니다.

### 변경

- F10 팝업을 상단 메뉴의 실제 라벨 위치에 맞추고 좁은 화면과 크기 변경에서 경계를 보정합니다.
- 공개 Tuivory 파사드로 앱·테스트의 tview/tcell 직접 import를 제거했습니다. 기존 편집기 replace는 입력·대용량 표시 호환성을 위해 유지합니다.
- SQL 강조 분석을 공개 Oracle SQL/PLSQL 분석기에 위임합니다. 원문·선택·키맵·자동완성 후보를 보존하며 다크 8색에서는 일곱 역할을 색상·속성으로 구분합니다.
- 비교표 한글 소실, 라이트 8색 분할선·비교표 구분선 대비, 40열 재접속 확인창의 취소 버튼 잘림을 수정했습니다. 현재 키맵은 공통 헤더의 강조색·밑줄·별표로 표시합니다.
- 팝업은 공통 SurfaceView/ShadowView로 표시합니다. 그림자는 오른쪽 1칸·아래 반 줄이며 ASCII는 점으로 대체합니다. 반 줄도 배치에는 1행을 예약합니다.

### 검증과 남은 범위

로컬 전체 일반 검사, 정적 분석과 Linux ARM64 빌드를 통과했습니다. 이전 v0.10.0 적용에서는 1,272개 화면 조합·5,088개 크기 상태, 포커스 192개·선택 72개 조합과 전체 race 검사를 통과했습니다. 최종 v0.10.1에서는 관련 팝업·한글 경계·비교표 검사 및 새 반 줄 출력 회귀를 확인했습니다. 한국어·영어·ASCII 실제 PTY의 크기 변경·정상 종료·임시 설정 보존을 확인하고 릴리스 버전의 README 화면을 갱신했습니다. 버전별 구체적 검증 범위는 [적용 기록](https://github.com/leechis7/lazyora/blob/v0.12.2/docs/tuivory-sync.md)에 구분합니다.

GitHub CI/Release는 전체 race·vet 및 Linux/Windows/macOS AMD64·ARM64 빌드를 수행합니다. 새 실DB 접속·원격 SSH/물리 폰트·CentOS·다른 OS의 실제 UI 검증은 포함하지 않습니다. 직접 import 제거와 전체 의미 컴포넌트/배치 전환 및 편집기 포크 제거는 별개이며 LORA-76 전체를 완료 처리하지 않습니다.

### 다운로드

환경에 맞는 실행파일 하나와 SHA256SUMS를 받으세요. Linux/macOS는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`

### English summary

v0.12.2 adopts Tuivory Go v0.10.1, fixes F10 placement, Korean popup text and low-color contrast, adds shared half-row shadows, and consumes the public SQL analyzer/root facade. Existing Oracle workflows remain unchanged; the editor replacement and further layout migration remain. See the English notes above.
