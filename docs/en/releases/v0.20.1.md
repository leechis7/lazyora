LazyOra v0.20.1 fixes grid commits and several display issues.

- Grid commits no longer report a false conflict after editing multiple cells in rows containing a small decimal such as `-0.0001`. Conflict checks still protect rows changed or deleted by another session.
- Click the Columns, Data, and DDL tabs in schema object details to switch views again. Object details and result-area tabs use one row.
- Shared popup shadows come from Tuivory Go v0.12.6. The connection form has less space between its panels, and the Settings note stays inside its border. Closed menus clear their highlight, and result-grid headers stand out from the body.

The decimal commit fix was reproduced and verified on Oracle Free. Mouse switching in object details was checked in a Linux ARM64 terminal. Existing shortcuts are unchanged.

AMD64 and ARM64 binaries are available for Linux, Windows, and macOS. Verify them against `SHA256SUMS`.
