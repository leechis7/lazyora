LazyOra v0.1.3은 SQL 파일·여러 편집 탭·커서 문장 실행부터 F5 스크립트·IN 바인드·예상 실행 계획·결과 내보내기까지 기본 Oracle 작업 흐름을 확장합니다.

## 주요 변경

- SQL 파일 열기·저장·다른 이름 저장, 한글 UTF-8/BOM/LF·CRLF 보존과 미저장 SQL 확인.
- 여러 SQL 탭과 탭별 파일·커서·선택·스크롤·조회 결과 유지. DB 연결·트랜잭션은 공유하며 실행 중 탭 조작은 잠깁니다.
- F9·Ctrl+Enter는 선택 영역 또는 커서 문장만 실행합니다. SQL 세미콜론, PL/SQL 별도 줄 /, 주석·문자열·Oracle q/nq 인용을 구분합니다.
- F5 SQL·PL/SQL 스크립트 순차 실행과 문장별 상태·처리 행·오류·다중 SELECT 결과. 첫 오류·취소에서 중단하며 앞선 DML을 자동 롤백하지 않습니다.
- IN 바인드 문자열·38자리 Oracle NUMBER·DATE·소수초 TIMESTAMP·NULL 입력. 반복/숫자 변수와 메모리 내 최근 값 재사용을 지원하며 값은 드라이버 인자로 전달합니다.
- Ctrl+E 예상 실행 계획: Operation·Options·객체·Cost·Rows 트리와 Access/Filter 상세. 원 SQL을 실행하거나 기존 DML을 커밋·롤백하지 않습니다.
- 조회된 결과 전체·선택 범위·현재 행을 CSV·TSV·실제 Excel(.xlsx)·Oracle INSERT로 저장합니다. NULL/원본 타입·한글을 보존하고 Excel은 텍스트 셀로 숫자 정밀도·앞자리 0·수식 모양 텍스트를 유지합니다. INSERT는 대상 테이블·컬럼을 지정해 파일만 생성하고 COMMIT을 넣지 않습니다.

## 자주 쓰는 새 키

| 키 | 동작 |
| --- | --- |
| Ctrl+O / Ctrl+S / Ctrl+Shift+S | SQL 열기 / 저장 / 다른 이름 저장 |
| Ctrl+N / Ctrl+W | SQL 탭 추가 / 닫기 |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Alt+PgDn / Alt+PgUp | 터미널용 다음 / 이전 탭 대체 키 |
| F5 | 선택 영역 또는 전체 스크립트 실행 확인 |
| Ctrl+E | 선택 SQL 또는 커서 문장의 예상 실행 계획 |
| Ctrl+Shift+E / Alt+W | 조회 결과 내보내기 |

Ctrl+Shift 조합을 구분하지 못하는 터미널은 메뉴나 대체 키를 사용하세요. 기존 Alt+L 접속, F2/Shift+F2 전체화면, Alt+C/Alt+R 커밋·롤백, F1 도움말은 유지합니다.

## 범위와 검증

- SQL 파일 최대 16 MiB, F5 최대 100문장·전체 60초, SELECT마다 최대 1,000행, 내보내기 파일 최대 64 MiB입니다. 내보내기는 현재 가져온 결과만 사용하며 DB 전체를 추가 조회하지 않습니다.
- 여러 PL/SQL 단위는 별도 줄 /로 구분합니다. SQL*Plus 명령·&치환·ROLLBACK TO·OUT/IN OUT·REF CURSOR·DBMS_OUTPUT·디버거는 미지원입니다.
- 실행 계획은 예상치이며 실제 실행 통계와 다를 수 있습니다. PLAN_TABLE 및 INSERT/SELECT/DELETE 권한이 필요하며 자동 DDL을 실행하지 않습니다.
- Excel은 텍스트 셀 정책입니다. INSERT의 긴 문자열·RAW·미지원 CLOB/BLOB/객체 타입 및 Excel의 행·열·셀 제한은 명시적으로 오류 처리합니다.
- Linux ARM64에서 race 테스트·vet·빌드·TUI 이벤트 루프와 한영 UI·미저장/트랜잭션 보호를 검증했습니다. 실제 실행파일의 Linux PTY 시험에서도 접속·F5·실행 계획·바인드·XLSX 저장·복사·커밋/롤백·확인 종료까지 통과했습니다. Docker Oracle Free에서 SQL/PLSQL·바인드·롤백·다중 결과·예상 계획의 DML 보존, INSERT 내보내기→재입력 원본 비교를 확인했습니다.
- GitHub CI는 Linux/Windows/macOS AMD64·ARM64 6종 빌드와 Windows AMD64 --version 실행을 검사합니다. 이번 변경의 실제 CentOS 7.4·Oracle 10g·Windows/macOS TUI 재시험과 macOS 코드 서명·공증은 포함하지 않습니다.

## 다운로드

Linux/Windows/macOS AMD64·ARM64 6종과 LICENSE·README·SHA256SUMS를 제공합니다. Go·Oracle Instant Client는 별도 설치하지 않습니다. Linux·macOS는 chmod +x로 실행 권한을 부여합니다.
