LazyOra v0.20.0은 **실행 → PL/SQL 디버거**를 추가합니다.

- 자기 스키마의 인자 없는 독립 프로시저를 지원합니다. `DEBUG CONNECT SESSION` 권한이 필요하며 대상은 미리 `COMPILE DEBUG`로 컴파일합니다.
- 중단점, 계속, 한 줄 실행, 호출 안·밖 이동, 현재 소스 줄·호출 스택·스칼라 변수 조회를 지원합니다.
- 두 임시 Oracle 세션에서 실행해 기존 SQL 편집기 트랜잭션을 유지합니다. 프로시저 내부의 명시적 커밋·DDL·자율 트랜잭션은 반영될 수 있습니다.

Oracle Free 23에서 중단점, 호출 진입·복귀, 변수 조회, 취소 및 기존 트랜잭션 보존을 검증했습니다. 10g·19c·RAC는 실환경 미검증입니다.

Linux·Windows·macOS용 AMD64·ARM64 실행파일을 제공하며 `SHA256SUMS`로 확인할 수 있습니다.
