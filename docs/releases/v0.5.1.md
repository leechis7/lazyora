LazyOra v0.5.1은 화면의 1,000행 조회 제한과 별개로 DB 전체 결과를 파일로 저장합니다. 대용량 출력 버퍼와 재현 가능한 성능 측정 도구를 추가했습니다.

## 사용 방법

1. SELECT를 실행한 뒤 **Alt+W**로 내보내기를 엽니다.
2. 저장 범위에서 **DB 전체 결과 (재조회)**를 선택합니다.
3. 원 SQL·저장 경로를 확인하고 내보내기를 선택합니다. 기본 선택은 취소입니다.

CSV·TSV·Excel(.xlsx)·Oracle INSERT(.sql)를 지원하며, 처리 행 수를 표시하고 **Esc 또는 취소 버튼**으로 중단할 수 있습니다.

## 변경 사항

- 결과를 만든 원 SQL과 당시 IN 바인드 값으로 재조회합니다. 편집 중인 SQL이나 나중에 입력한 값으로 바꿔 실행하지 않습니다. 재접속·바인드 값 지우기는 이전 탭·스크립트 결과의 재조회 정보를 제거합니다.
- DB 행을 읽으며 순차 저장해 전체 결과를 메모리에 누적하지 않습니다. 전체 내보내기에는 앱의 1,000행·64 MiB·60초 제한을 적용하지 않습니다. 화면 조회와 기존 가져온 결과·선택 범위·현재 행 저장은 유지합니다.
- 모든 형식에 **256 KiB 공통 출력 버퍼**를 적용해 작은 파일 쓰기를 묶습니다. 정상 완료 시 Flush하며 마지막 쓰기 오류도 실패로 처리합니다.
- Excel은 시트당 1,048,576행에 도달하면 Results_2 등으로 자동 분할하고 선택한 헤더를 각 시트에 반복합니다. 원본 정밀도·앞자리 0·수식 모양 텍스트를 위한 텍스트 셀 정책을 유지합니다.
- 읽기·쓰기·커서 종료 오류, 취소, 감지한 외부 파일 변경 시 기존 파일을 보존합니다. 임시 파일과 DB 커서를 정리하고 완전히 성공했을 때만 대상 파일을 교체합니다.

## 범위와 검증

원 SQL을 **다시 조회한 시점의 결과**이므로 화면 데이터와 달라질 수 있습니다. SQL 내 함수의 부작용도 따릅니다. 현재 공유 DB 세션·트랜잭션을 사용하며 자동 COMMIT/ROLLBACK을 수행하지 않습니다. SELECT FOR UPDATE는 재조회하지 않습니다. DB·드라이버·네트워크 및 단일 셀·지원 타입 제한은 계속 적용됩니다. 재조회 시 컬럼 목록이 바뀌면 다시 실행하도록 안내합니다.

- Linux ARM64에서 전체 race 테스트·vet·빌드와 실제 터미널 PTY 시험을 통과했습니다. 2,507행 전체 저장·기본 취소·명시적 재조회 확인 및 기존 접속·복사·트랜잭션 종료를 확인했습니다.
- Oracle Free에서 원 바인드 보존, 1,000행 화면 제한과 2,507행 전체 저장, 1,500행에서 취소 시 기존 파일·미커밋 DML 보존과 명시적 롤백을 확인했습니다. 버퍼가 실제 파일에 일부 기록된 뒤 취소하는 시험과 최종 Flush 오류 시험도 포함합니다.
- 네 형식의 10만·100만 행 파일 저장과 Oracle 조회 포함 측정, 파일 전체 행 수 검사를 수행했습니다. 현재 ARM64 2 vCPU·로컬 Oracle Free·시험용 3컬럼 기준 100만 행은 CSV 4.85초·TSV 4.59초·INSERT 6.05초·Excel 9.55초, 최대 RSS 약 25~28 MiB였습니다. 단일 환경의 관측값이며 다른 환경의 속도를 보장하지 않습니다.
- `make -C test/oracle export-bench`로 성능 시험을 재현할 수 있습니다. [측정 조건과 원본 결과](https://github.com/leechis7/lazyora/blob/v0.5.1/test/oracle/benchmarks/export-2026-10-20.md)를 참고하세요.
- 이번 변경의 실제 CentOS 7.4·Oracle 10g·Windows/macOS TUI 재시험은 포함하지 않습니다. GitHub CI·Release에서 Linux/Windows/macOS AMD64·ARM64 교차 빌드와 Windows AMD64 버전 실행을 검사합니다.

## 다운로드

Linux·Windows·macOS AMD64/ARM64 6종과 LICENSE·README·SHA256SUMS를 제공합니다. Go나 Oracle Instant Client는 별도 설치하지 않습니다. Linux·macOS는 `chmod +x`로 실행 권한을 부여하세요.
