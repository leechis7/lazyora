LazyOra v0.12.3은 Tuivory Go v0.11.1로 셀 편집·실제 커서와 변경 표식을 정리한 패치 릴리스입니다.

### 수정

- Enter와 더블클릭 모두 선택한 셀 안에서 즉시 편집합니다. 편집 불가 셀은 상세창을 자동으로 열지 않고 사유를 안내합니다. 셀 상세는 문맥/보기 메뉴에서 열며 Alt+D 별도 편집창은 유지합니다.
- 공개 Grid 편집 API로 자체 셀 입력 렌더러를 제거했습니다. 변경 확인을 취소하면 같은 초안과 커서로 돌아갑니다. 승인 전 UPDATE를 보내지 않고, 결과/탭 교체 뒤 오래된 승인은 차단합니다.
- 실제 터미널 커서의 위치·가시성과 문자 폭·클리핑은 Tuivory가 담당합니다. 커서 모양·깜빡임은 터미널 설정을 따르며 공개 TTY 필터로 강제 커서 제어와 SecureCRT의 `q` 누출을 방지합니다.
- 변경 셀의 배경·`*`와 행 번호의 집계 `*`를 분리했습니다. 변경하지 않은 셀은 행 전체 상태 때문에 변경색으로 칠해지지 않습니다. 커밋·롤백 후 표시를 해제합니다.
- Ctrl+U 지우기, Alt+Delete NULL, 변경 확인 기본 진행 버튼, 원문 복사와 Oracle ROWID/원본 컬럼 검증·수동 트랜잭션을 유지합니다.

### 검증과 범위

로컬 전체 테스트·관련 race·vet·Linux ARM64 빌드를 통과했습니다. 실제 앱 커서96조합(한영·테마·색상 수·문자 모드·Enter/더블클릭), 변경 셀/행 표식24조합과 승인 대기·취소·NULL·Unicode·오래된 승인·포커스 복귀를 확인했습니다. ARM64 PTY의 TERM 미지정/빈 값/ansi/xterm4환경에서 데모 시작·확인 후 종료 및 강제 커서 명령 누출 차단을 검증했습니다. [한영 검증 기록](https://github.com/leechis7/lazyora/blob/v0.12.3/docs/audits/lora-76-tuivory0111.md).

GitHub CI/Release는 전체 race·vet와 Linux/Windows/macOS AMD64·ARM64 빌드를 수행합니다. 실DB UPDATE·CentOS·물리 SecureCRT/Windows/macOS 콘솔의 깜빡임은 이번에 시험하지 않았습니다. SDK에 새로 추가된 열 고정·범위 붙여넣기·Tab 편집 이동 등은 이번 릴리스의 제품 명령으로 제공하지 않습니다. SQL 편집기의 기존 backend replace와 다른 LORA-76 범위는 남아 있습니다.

### 다운로드

실행 환경에 맞는 파일 하나와 `SHA256SUMS`를 받으세요. Linux/macOS에서는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`

### English summary

v0.12.3 fixes Enter/double-click in-cell editing, migrates its UI to Tuivory Go v0.11.1 real-cursor/host-approval APIs, restores drafts after rejected review and independent dirty-row/cell cues. Oracle validation and transactions remain host-owned. See the English release notes for verification and limitations.
