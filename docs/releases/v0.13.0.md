LazyOra v0.13.0은 그리드 일괄 편집, 접속별 환경 라벨, SQL 즐겨찾기를 추가합니다.

- 편집 가능한 결과에서 Enter·더블클릭으로 셀을 수정하고 Tab·Shift+Tab으로 다음·이전 셀로 이동합니다. 수정 초안은 Alt+C로 한 번에 반영하고 Alt+R로 버립니다. 재실행 전에 초안 폐기를 확인하며, 일괄 반영에 실패하면 초안을 유지합니다.
- 접속창에서 `[PROD · 서울 운영]` 같은 사용자 지정 환경 라벨을 설정하고 현재 접속과 위험 SQL·스크립트 실행 확인창에서 확인합니다.
- F8 SQL 이력에서 Alt+S로 즐겨찾기에 저장하고 Alt+F로 목록을 엽니다. 이름·태그로 검색해 새 탭에 열 수 있습니다. 열 때 SQL은 실행되지 않습니다. SQL 본문은 로컬에 평문으로 저장됩니다.
- Tuivory Go v0.12.2를 적용해 팝업 버튼을 가운데 정렬하고 결과 그리드의 현재 셀과 선택 범위를 구분합니다. 흑백 8색에서는 두 영역에 같은 색을 사용합니다.

### 검증

Docker Oracle Free에서 일괄 편집, 커밋·롤백, ROWID 편집, 커서 취소 등을 포함한 통합 시험을 통과했습니다.

### 다운로드

Linux AMD64·ARM64, Windows AMD64·ARM64, macOS AMD64·ARM64를 지원합니다. 운영체제와 아키텍처에 맞는 실행파일을 받고 `SHA256SUMS`로 확인하세요. Linux/macOS에서는 `chmod +x <실행파일>`로 실행 권한을 부여하세요.
