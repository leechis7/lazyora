LazyOra v0.10.0은 패널 배치·스키마 탐색·접속 관리와 편집기 키맵을 확장한 기능 릴리스입니다.

## 주요 변경

- **패널 크기 조절:** SQL·결과 사이와 스키마·오른쪽 영역 사이의 분할선을 마우스로 드래그합니다. Alt+F8 키보드 모드에서는 방향키로 조절하고 Home으로 초기화하며 Enter·Esc로 마칩니다.
- **스키마 실시간 검색:** Alt+I로 객체 검색에 이동합니다. 입력할 때마다 현재 사용자·객체 종류에서 이름이 일치하는 객체만 표시합니다.
- **SQL 탭 이름 변경:** 파일에 연결되지 않은 탭은 SQL 탭 메뉴에서 이름을 변경할 수 있습니다. 파일에 연결된 탭은 파일명을 사용합니다.
- **마스터 잠금 해제 재사용:** 프로그램 실행 중 같은 암호 저장소의 잠금 해제 상태를 접속 작업 공간 간에 재사용합니다. 마스터 암호 평문을 보관하지 않으며 명시적 잠금·종료 시 키를 정리합니다. 외부에서 저장소가 바뀌면 다시 잠금을 해제해야 합니다.
- **작업 공간 창 개선:** 공통 안내를 한 번만 표시하고 목록 클릭은 선택만 수행합니다. 전환 버튼 또는 Enter로 전환을 확정합니다.
- **메뉴 정리:** 기능별 구분선과 긴 편집·보기 메뉴의 2단계 하위 메뉴를 추가했습니다. Enter·오른쪽 방향키로 하위 메뉴를 열고 왼쪽 방향키·Esc로 돌아갑니다. Alt+메뉴 문자는 상위 메뉴를 선택합니다.
- **접속 테스트:** 접속창의 Alt+V 또는 접속 테스트 버튼으로 별도 임시 세션에서 접속을 확인합니다. 현재 작업용 세션·조회 결과·미커밋 트랜잭션은 유지합니다.
- **편집기 키맵 확장:** 기존 기본 키맵을 Toad로 표시하고 기본 선택과 설정 호환성을 유지합니다. VS Code·IntelliJ IDEA 키맵을 추가했으며 도움말 메뉴의 편집기 키맵 비교표 또는 F1의 Alt+K로 실제 단축키를 비교할 수 있습니다.
- **영어 소개:** README 상단에 영어 프로젝트 요약을 추가했습니다.

## 키맵 지원 범위

Toad·Vim·Notepad++·VS Code·IntelliJ IDEA의 5종 키맵을 제공합니다. 새 IDE 키맵은 Windows/Linux 기준의 주요 편집 조합이며 IDE 전체 호환이나 다중 커서·macOS Command 조합을 지원한다는 의미는 아닙니다. 터미널에서 전달하지 못하는 조합은 메뉴 또는 대체 조합을 사용하세요. SQL 실행·커밋·롤백 같은 앱 공통 키는 유지합니다.

## 검증

Linux ARM64에서 전체 Go race 테스트·vet·빌드와 실제 터미널의 키맵·도움말·전체화면·TERM 호환 검사를 통과했습니다. Oracle Free에서는 접속 테스트 중 기존 미커밋 트랜잭션 보존과 결과 편집 회귀 검사를 확인했습니다. GitHub CI에서는 전체 테스트·vet, Linux·Windows·macOS AMD64/ARM64 빌드, Windows 실행파일 실행 및 Windows/macOS 모의 UI·설정 경로 검사를 수행합니다. 실제 CentOS 7.4·Oracle 10g와 Windows/macOS의 전체 TUI 재시험은 이번 배포에서 수행하지 않았습니다.

색상 수·테마별 전체 화면 전수 검토(LORA-69)는 후속 백로그이며 이번 릴리스에 포함되지 않습니다.

## 다운로드

Linux·Windows·macOS AMD64/ARM64 실행파일 6종과 LICENSE·README.md·TVIEW-LICENSE.txt·SHA256SUMS를 제공합니다. Go나 Oracle Instant Client를 별도로 설치하지 않습니다. Linux·macOS는 `chmod +x`로 실행 권한을 부여하세요.
