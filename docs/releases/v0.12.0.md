LazyOra v0.12.0은 공개 Tuivory Go v0.4.0의 공통 메뉴·결과 그리드와 표면 스타일을 적용한 기능 릴리스입니다.

### 변경

- 공통 메뉴 막대·중첩 메뉴·뒤로 이동·구분선·비활성 표시·포인터 탐색을 사용합니다. F10·Shift+F10·Alt 진입, ←/→ 상위 메뉴 이동, 원래 창 포커스 복원은 유지합니다.
- 결과 본체를 같은 공통 Grid의 data 프리셋/옵션으로 그립니다. 행 번호·구분선·줄무늬·숫자 정렬·현재/범위/변경 셀·상태줄을 연결하고, **헤더의 컬럼 구분선을 드래그해 열 너비를 조절**할 수 있습니다. 기존 너비 명령도 유지합니다.
- 메뉴 단일선·제목·배경·한글 경계 보호를 공개 PanelView에 맡기고 별도 테두리 우회 구성을 제거했습니다. 일반 포커스 패널의 이중선은 유지합니다.
- 일반 글자를 실제 표면에 맞추고 비활성 항목은 회색/Dim으로 표시합니다. 비활성 접두사를 제거하고 클릭·포커스·실행은 차단합니다. 8색 Dim의 실제 밝기는 터미널에 따라 다릅니다.
- 현재 행 표식은 `>`, 공통 폭 생략은 `~`입니다. 미커밋 셀 배경·상태줄 `*`는 유지하고 행번호 `*`는 생략합니다. 원본 값·ROWID 매핑·편집 확인·커밋/롤백·복사·내보내기와 기존 전역 단축키를 보존합니다.
- 한영 사용/내장 가이드·README 및 실제 실행파일의 데모 화면을 갱신했습니다.

### 검증과 범위

전체 로컬 Go race(UI 208.583초), 정적 분석·Linux ARM64 빌드, 24개 언어/테마/색상 조합 및 새 12팔레트 비활성/표면 검사를 통과했습니다. 설정·DB 환경을 격리한 실제 한글/영어 Unicode·영어 ASCII PTY에서 일반 화면과 열린 메뉴의 총24회 SIGWINCH 크기 변경 이후 메뉴·복사·상세·접속 팝업·정상 종료와 설정 보존을 확인했습니다. 릴리스 버전·내장 문서·캡처도 추가 확인합니다.

GitHub CI·Release는 전체 검사와 Linux/Windows/macOS AMD64/ARM64 빌드를 수행합니다. 실제 원격 단말·폰트·CentOS·다른 OS의 UI·새 Oracle 실DB 접속은 이번 검증과 구분합니다. Tuivory의 private playground 리사이즈 수정 코드를 복사하지 않았으며 LazyOra 자체 앱을 시험했습니다. 남은 LORA-76 앱 패널/분할/하단 개선은 이번 릴리스로 완료하지 않습니다.

### 다운로드

OS·CPU에 맞는 실행파일 하나와 `SHA256SUMS`를 확인하세요. Linux/macOS에서는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`

### English summary

LazyOra v0.12.0 adopts public Tuivory Go v0.4.0 menus, configurable result grids, single menu borders, surface-aware text and improved disabled cues. Drag header dividers to resize columns; retain existing shortcuts, original-value copy, guarded ROWID editing and transactions. Current-row/clipping markers are `>`/`~`; edited cells retain background/status `*`. See the [English release notes](https://github.com/leechis7/lazyora/blob/v0.12.0/docs/en/releases/v0.12.0.md).
