LazyOra v0.1.1은 macOS 실행파일을 추가하고 README를 빠른 시작 중심으로 정리한 릴리스입니다. SQL·트랜잭션 동작과 단축키는 v0.1.0과 같습니다.

## 변경 사항

- Intel Mac(AMD64)·Apple Silicon(ARM64) 실행파일을 제공합니다.
- GitHub CI에서 전체 6종을 빌드하고 릴리스 파일과 SHA256SUMS에 포함합니다.
- README는 다운로드·실행·접속·핵심 단축키 중심으로 줄였습니다. 상세 사용법과 빌드·호환성·검증 기록은 별도 문서에서 확인합니다.

## 다운로드

Go·Oracle Instant Client를 별도로 설치할 필요가 없습니다.

| 환경 | 실행파일 |
| --- | --- |
| Linux x86_64 | `lazyora-linux-amd64` |
| Linux ARM64 | `lazyora-linux-arm64` |
| Windows x86_64 | `lazyora-windows-amd64.exe` |
| Windows ARM64 | `lazyora-windows-arm64.exe` |
| macOS Intel | `lazyora-darwin-amd64` |
| macOS Apple Silicon | `lazyora-darwin-arm64` |

Linux·macOS는 다운로드 후 `chmod +x 파일명`으로 실행 권한을 주고 터미널에서 실행합니다. `--demo`로 DB 없이 화면을 둘러보고 `--version`으로 버전을 확인할 수 있습니다. SHA256SUMS에는 실행파일·LICENSE·README의 체크섬을 제공합니다.

## 검증과 제한

- 로컬 Linux ARM64에서 race 테스트·vet·ARM64 빌드를 확인했습니다. GitHub CI·Release가 전체 대상 교차 빌드를 수행하며 CI는 Windows AMD64 버전 명령도 실행합니다.
- macOS는 CGO 없는 교차 빌드입니다. 코드 서명·공증과 실Mac TUI·DB 접속 검증은 포함하지 않습니다.
- 이번 변경에서 Oracle 실DB·CentOS 시험을 재실행하지 않았습니다. 기존 SQL 지원 범위와 제한은 v0.1.0을 따릅니다.
