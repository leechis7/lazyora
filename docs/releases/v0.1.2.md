LazyOra v0.1.2는 위험 SQL 실행 확인, 선택적 DB 비밀번호 암호화 저장, 언어 미설정 시 로캘 적용을 제공합니다. 기존 실행·커밋·롤백 단축키는 유지합니다.

## 위험 SQL 실행 전 확인

- DDL·관리 명령과 최상위 WHERE 없는 UPDATE·DELETE를 실행하기 전에 경고 사유와 실행 대상 SQL을 표시합니다. 조건 판별이 불확실한 UPDATE·DELETE도 확인합니다.
- 기본 선택과 Esc는 취소입니다. 실행 버튼을 명시적으로 선택해야 DB 작업과 실행 이력을 제출합니다. 선택 SQL이 있으면 해당 부분만 검사·실행하며 확인한 SQL 스냅샷을 사용합니다.
- 주석·문자열·따옴표 식별자·Oracle q/nq 인용·바인드 이름·서브쿼리 안의 WHERE를 바깥 조건으로 오인하지 않습니다.
- Tab·방향키·마우스·F1을 지원하며 소스 적용·컴파일의 기존 DDL 확인은 유지합니다.

이 검사는 영향 행 수나 WHERE 선택도를 예측하지 않습니다. WHERE 1=1, PL/SQL·동적 SQL·프로시저 내부 SQL·MERGE 등은 분석하지 않으며, 경고가 없다는 것이 안전하다는 뜻은 아닙니다.

## 선택적 암호화 저장

- 접속 화면에서 비밀번호 저장(암호화)을 선택하고 저장할 때만 DB 비밀번호를 보관합니다. 기본은 미저장입니다.
- 최초 마스터 비밀번호는 8글자 이상으로 설정합니다. 마스터 자체는 저장하지 않고 Argon2id로 키를 유도하여 AES-256-GCM으로 별도 저장소를 암호화합니다.
- Alt+K 또는 도구 → 암호 관리에서 잠금 해제·잠금·마스터 변경·전체 초기화를 합니다. 접속별 저장을 해제하면 해당 저장 암호를 삭제합니다.
- 마스터를 잊어도 Esc로 잠금 해제를 취소하고 DB 비밀번호를 직접 입력하여 접속할 수 있습니다. 저장소 초기화나 재저장은 필요하지 않습니다.
- 마스터는 복구할 수 없습니다. 같은 OS 계정/설정 경로를 공유하면 저장소도 공유하며 Go/OS 메모리 복사본의 완전 삭제를 보장하지 않습니다.

## 언어 기본값

언어 설정이 없거나 빈 값이면 LC_ALL → LC_MESSAGES → LANG을 확인해 한국어(ko) 로캘은 한국어, 나머지는 영어로 표시합니다. 명시적으로 저장한 언어와 기존 마우스 설정은 유지합니다.

## 다운로드와 검증

Go·Oracle Instant Client 없이 실행하는 Linux/Windows/macOS AMD64·ARM64 6종을 제공합니다. Linux·macOS는 chmod +x로 실행 권한을 부여합니다. SHA256SUMS에 실행파일·LICENSE·README의 체크섬을 제공합니다.

로컬 Linux ARM64에서 race 테스트·vet·빌드와 버전 확인, TUI 이벤트 루프·암호화 파일 및 80×24 한영 경고 화면을 검사했습니다. GitHub CI·Release는 전체 대상 교차 빌드와 테스트·vet를 수행하며 CI에서 Windows AMD64 버전 명령을 실행합니다. 이번 변경에서 실Oracle·CentOS·실Windows/macOS TUI 접속을 재시험하지 않았습니다. macOS 코드 서명·공증은 포함하지 않습니다.
