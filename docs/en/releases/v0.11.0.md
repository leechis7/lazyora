LazyOra v0.11.0 adds schema-tree navigation and terminal character compatibility modes.

### Changes

- **Schema tree**: use public Tuivory Go v0.1.0. Right/Space or the disclosure arrow lazily fetches table/view columns and data types. Left collapses/moves to the parent; Alt+Left/Right pans horizontally. User/type selection, live filtering and Enter/name-click details remain available.
- **Auto/Unicode/ASCII display**: save the mode in Tools → Settings → Character display (Alt+D). `--display-mode auto|unicode|ascii` overrides only the current run. Auto estimates output encoding/glyph support and falls back to ASCII/English UI when required characters are unsupported.
- Original SQL, database values, application copy/export and Korean preferences remain intact. ASCII `?` characters are display substitutions. Actual font coverage cannot be detected; mouse/color support is independent.
- Korean/English README, usage, terminal and Tuivory integration documentation are current. No separate Tuivory installation is required.

### Verification and limits

Full Go race tests, static checks and the local Linux ARM64 build passed, along with tree checks across 12 theme/color profiles, 144 simulated ASCII scenes and three local PTY scenarios. GitHub CI/Release runs supported builds and automated checks for Linux/Windows/macOS AMD64/ARM64. This release does not add fresh remote SecureCRT/MobaXterm, old CentOS or live Oracle verification.

### Downloads

Choose one executable for your OS/CPU and verify `SHA256SUMS`. Make Linux/macOS files executable.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`
