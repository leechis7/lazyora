LazyOra v0.11.3 refines schema-tree display and component-ownership documentation.

### Changes

- Remove duplicate column icons: Unicode `· · ID` → `· ID`, ASCII `. C ID` → `. ID`. Recover two cells per line for names/types.
- Retain public Tuivory Go v0.2.0 leaf markers, indentation, navigation, identity and details actions. No shared-renderer edits or source copying.
- Clarify that Tuivory provides reusable components while LazyOra owns actual screen composition/layout, global shortcuts and action binding. Do not transfer all application-composition code to the library.
- Refresh Korean/English README images from the executable demo. TVR-17 grid options/presets remain a request, not a feature implemented in this release.

### Verification and scope

Check existing tree expansion/stale response/filter/cache/theme/width/large-list/parent-action regressions, full Go race tests, static checks and local Linux ARM64 builds. Bilingual demo images capture actual database-free executable PTY output, not live Oracle results.

GitHub CI/Release runs supported Linux/Windows/macOS AMD64/ARM64 builds and automated checks. Fresh remote-terminal/font/CentOS/live-Oracle verification is separate.

### Downloads

Choose one executable for your OS/CPU and verify `SHA256SUMS`. Make Linux/macOS files executable.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`
