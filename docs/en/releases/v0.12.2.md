LazyOra v0.12.2 is a patch adopting Tuivory Go v0.10.1 and improving menu placement, popups and low-color readability.

### Changes

- Anchor F10 popups to actual top-bar labels, clamping them through resizing and narrow screens.
- Remove direct tview/tcell imports from application code/tests through the public Tuivory facade. Retain the editor replacement for input and large-document compatibility.
- Delegate highlighting to the public Oracle SQL/PLSQL analyzer while preserving original SQL, selection, keymaps and completion candidates. Dark/8 profiles distinguish seven roles through colors/attributes.
- Fix Korean glyph loss in comparison tables, light/8 splitters and comparison separator contrast, and clipped Cancel buttons in 40-column reconnect dialogs. Shared accent/underline/star styling marks the current keymap.
- Use common SurfaceView/ShadowView popup rendering: one cell right and half a row down, with ASCII dots. The half-row appearance still reserves a full layout row.

### Verification and remaining scope

Full local ordinary tests, vet and Linux ARM64 builds passed. The prior v0.10.0 integration passed 1,272 screen combinations/5,088 resize states, 192 focus and 72 choice combinations and a full race suite. Final v0.10.1 checks cover relevant popup/wide-boundary/comparison paths and new half-row output regressions. Actual Korean/English/ASCII PTYs verify resizing, normal exit and unchanged temporary settings; README captures were refreshed for the release version. See [version-specific evidence](https://github.com/leechis7/lazyora/blob/v0.12.2/docs/en/tuivory-sync.md).

GitHub CI/Release runs full race/vet and Linux/Windows/macOS AMD64/ARM64 builds. New live Oracle, remote SSH/physical-font/CentOS or other-OS actual UI certification is outside scope. Zero direct imports does not imply full semantic-component/layout migration or editor-fork removal; broader LORA-76 remains open.
