LazyOra v0.20.0 adds **Execute → PL/SQL debugger**.

- Supports standalone parameterless procedures in your own schema. Requires `DEBUG CONNECT SESSION` and a target compiled with `COMPILE DEBUG`.
- Supports breakpoints, continue, stepping over/into/out of calls, source location, the call stack, and scalar watches.
- Uses two temporary Oracle sessions and preserves the SQL editor transaction. Explicit commits, DDL, and autonomous transactions inside the procedure can still persist.

Oracle Free 23 tests verified breakpoints, stepping into and out of a call, variable inspection, cancellation, and transaction isolation. Oracle 10g, 19c, and RAC were not tested live.

AMD64 and ARM64 binaries are available for Linux, Windows, and macOS. Verify them against `SHA256SUMS`.
