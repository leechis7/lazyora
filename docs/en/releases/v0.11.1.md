LazyOra v0.11.1 fixes wide-glyph boundary corruption in shared popups.

### Fix

- Fix missing connection/settings/About and other shared popup borders when a two-cell Korean/CJK/emoji glyph crosses a card or shadow boundary.
- Clear only intersecting glyphs, preserving intact outside glyphs/styles, original SQL/results and focus.
- Retain public Tuivory Go v0.1.0. A general public popup/overlay protection API is follow-up work in the separate Tuivory project.

### Verification

Confirmed the reproduction fails against the physical output buffer before the fix. After the fix, checked 1,728 frames across three dialogs, Korean/English, 12 theme/color combinations, resizing, Korean/CJK/emoji/combining marks and repeated drawing, plus background restoration. Full Go race tests, static checks, local Linux ARM64 build and existing popup/choice/ASCII regressions passed.

GitHub CI/Release runs supported Linux/Windows/macOS AMD64/ARM64 builds and automated checks. This release adds no fresh remote SecureCRT/MobaXterm, old CentOS, actual font or live Oracle verification.

### Downloads

Choose one file for your OS/CPU and verify the attached `SHA256SUMS`. Make Linux/macOS binaries executable.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`
