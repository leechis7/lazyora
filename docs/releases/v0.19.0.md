LazyOra v0.19.0은 조회 결과·실행 메시지·DBMS_OUTPUT을 하나의 결과 영역에 모았습니다.

- 결과 영역에서 **Shift+Tab**으로 탭 줄에 들어가 **←/→**로 선택하고 **Enter**로 엽니다. 마우스와 **보기** 메뉴도 사용할 수 있습니다. **Alt+P**는 DBMS_OUTPUT을 바로 엽니다.
- F9·F5가 끝나도 선택된 탭과 SQL 편집기 포커스가 유지됩니다. 새 내용은 `*`, 실행·출력 오류는 `!`로 표시합니다.
- 결과와 실행 메시지는 SQL 탭별로, DBMS_OUTPUT은 접속별로 유지합니다. 출력 탭에서 **Alt+E**로 수집을 켜거나 끄고, **Ctrl+C**로 복사하거나 **Alt+D**로 비울 수 있습니다.

Oracle Free에 연결한 실제 터미널에서 탭 전환과 포커스 유지, DBMS_OUTPUT 조작을 검증했습니다. 전체 터미널 시나리오의 스키마 탐색 시험은 v0.18.0에서도 재현된 `CHANGED_AT` 대기 문제로 완료하지 못했습니다.

Linux·Windows·macOS용 AMD64·ARM64 실행파일을 제공하며 `SHA256SUMS`로 확인할 수 있습니다.
