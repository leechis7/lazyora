LazyOra v0.20.1은 그리드 커밋과 화면 표시를 수정합니다.

- 원본 행에 `-0.0001` 같은 작은 소수가 있으면, 여러 셀을 수정한 뒤 커밋할 때 행이 변경됐다고 잘못 판단하던 문제를 수정했습니다. 다른 세션이 수정하거나 삭제한 행을 덮어쓰지 않도록 기존 충돌 검사는 유지합니다.
- 스키마 객체 상세의 컬럼·데이터·DDL 탭을 다시 마우스로 전환할 수 있습니다. 객체 상세와 결과 영역의 탭은 한 줄로 표시합니다.
- Tuivory Go v0.12.6의 공통 팝업 그림자를 적용했습니다. 접속창의 상자 간격을 줄였고 설정 안내가 테두리와 겹치지 않게 했습니다. 메뉴를 닫을 때 선택 강조를 지우고, 결과 그리드 헤더는 본문과 구분합니다.

작은 소수의 커밋 문제는 Oracle Free에서 재현·검증했고, Linux ARM64 터미널에서 객체 상세 탭 전환을 확인했습니다. 기존 단축키는 그대로입니다.

Linux·Windows·macOS용 AMD64·ARM64 실행파일을 제공하며 `SHA256SUMS`로 확인할 수 있습니다.
