LazyOra v0.11.1은 공통 팝업의 한글 경계 깨짐을 수정하는 패치 릴리스입니다.

### 수정

- 접속·설정·앱 정보 등 공통 팝업을 열 때, 배경의 두 칸 문자(한글·CJK·이모지)가 카드·그림자 경계에 걸려 테두리 선이 사라지는 문제를 수정했습니다.
- 경계에 걸친 문자만 온전히 지워 바깥의 온전한 글자·스타일과 SQL·결과 원문·포커스를 보존합니다.
- 공개 Tuivory Go v0.1.0 의존성을 유지합니다. 일반 팝업/오버레이용 공통 보호 API의 Tuivory 보완은 별도 프로젝트 범위입니다.

### 검증

수정 전 실제 출력 버퍼에서 실패하는 재현 검사를 확인했습니다. 수정 후 접속·설정·앱 정보 × 한영 × 12개 테마/색상 조합, 크기 왕복·한글/CJK/이모지/결합 문자·반복 그리기 1,728프레임을 검사하고 배경 복원을 확인했습니다. 전체 Go race 테스트·정적 검사·Linux ARM64 빌드와 기존 팝업·콤보박스·ASCII 회귀 검사가 통과했습니다.

GitHub CI·Release는 Linux/Windows/macOS AMD64/ARM64의 지원 빌드와 자동 검사를 수행합니다. 실제 원격 SecureCRT/MobaXterm·구형 CentOS·폰트·실DB 접속 시험을 이번에 새로 수행한 것은 아닙니다.

### 다운로드

OS·CPU에 맞는 파일 하나를 선택하고 첨부한 `SHA256SUMS`로 검증하세요. Linux/macOS에서는 실행 권한을 부여합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- macOS: `lazyora-darwin-amd64`, `lazyora-darwin-arm64`
