LazyOra v0.14.0 adds schema data browsing and table structure comparison across Oracle connections.

- Open a table, view, or materialized view in the schema tree to switch between Columns, Data, and DDL on the right. Alt+V opens the data preview, and Ctrl+N extends the preview. Existing SQL results and transactions stay available.
- Select a table row and press Alt+F or choose **Related rows** to follow a foreign key to parent or child rows in a separate read-only grid. Composite foreign keys are supported.
- Choose **Tools → Compare table structures** and select two open Oracle connections. See tables visible only on one side and differences in column order, type, length or precision, nullability, and defaults. The comparison uses metadata visible to each connection.

### Verification

Oracle Free integration tests verified preservation of existing SQL cursors during data previews, bidirectional composite foreign-key navigation, and comparisons of column length and defaults across two independent sessions with pending transactions preserved.

### Download

Download the AMD64 or ARM64 executable for Linux, Windows, or macOS and verify it against `SHA256SUMS`. On Linux and macOS, grant execute permission with `chmod +x <executable>`.
