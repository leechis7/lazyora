LazyOra v0.1.0은 스키마·객체 탐색과 Toad 기준 키 조작, 소스 편집·컴파일, 결과 복사 및 미커밋 실행 내역 확인을 제공합니다.

## 주요 단축키 변경

v0.0.1의 F2 접속은 Alt+L로, F4 SQL 실행은 F9로 변경했습니다. 커밋·롤백은 Alt+C·Alt+R입니다.

| 동작 | v0.1.0 키 |
| --- | --- |
| 도움말 | F1 |
| 접속 화면 | Alt+L |
| SQL 실행 | F9 / Ctrl+Enter / Shift+F9 / Alt+Enter |
| 객체 상세 / 객체명 입력 조회 | F4 / Ctrl+D |
| 쿼리 / 결과 전체화면·복원 | F2 / Shift+F2 |
| 쿼리·결과 전환 | F6 |
| SQL 전체 지우기(확인 후 처리) | F7 |
| SQL 실행 이력 | F8 |
| 문맥 메뉴 | F10 / 우클릭 |
| 커밋 / 롤백 | Alt+C / Alt+R |
| 스키마 브라우저 표시·숨김 | Alt+B |
| 브라우저 사용자 / 객체 종류 선택 | Alt+U / Alt+O |
| SQL 찾기 / 바꾸기 | Ctrl+F / Ctrl+R |
| 다음 / 이전 찾기 | F3 / Shift+F3 |
| 결과 셀·범위 / 행 복사 | Ctrl+C / Alt+Y |
| 실행 중 취소 / 종료 확인 | Esc / Ctrl+Q |

환경설정은 **도구 → 설정(Alt+T, Enter)**에서 엽니다. 소스 편집 화면의 **F9**는 적용·컴파일입니다. F5 스크립트 실행·Ctrl+F9 구문 검사·F11 디버거는 아직 미지원입니다.

## 새 기능과 개선

- 일반 실행 시 접속 창을 먼저 표시하며 Service Name/SID·별칭 저장을 지원합니다. 비밀번호는 저장하지 않습니다.
- 스키마 브라우저 위쪽에서 사용자·객체 종류를 선택하고 아래 목록을 탐색합니다. 기본값은 접속 계정과 테이블입니다.
- 테이블·뷰·구체화 뷰·함수·프로시저·패키지/본문·시퀀스·동의어·인덱스·트리거·타입/본문의 13종을 지원합니다.
- 컬럼 코멘트·데이터 타입·NULL 허용 여부, 객체 정보, 소스·인자 조회와 소스 편집·컴파일 오류를 확인할 수 있습니다.
- 종료 시 미커밋 가능 작업을 확인합니다. **내역 보기(Alt+V)**와 **세션 → 미커밋 내역 보기**에서 SQL·실행 시각·처리 행 수·오류를 조회합니다.
- 결과 셀·행·드래그 범위의 TSV 복사와 클립보드 미지원 터미널용 복사 미리보기를 제공합니다.
- 찾기·바꾸기, 메모리 SQL 이력, 창 전체화면과 메뉴를 유지하는 최대화, 한글·영문 도움말 항목 이동을 지원합니다.
- 버튼 좌우 이동과 선택 표시, 회색 단일선 메뉴, 8·16색 및 SecureCRT 커서·키 입력 호환성을 개선했습니다.

## 다운로드와 검증

첨부 실행파일은 Go·Oracle Instant Client 설치 없이 실행합니다.

- Linux: `lazyora-linux-amd64`, `lazyora-linux-arm64`
- Windows: `lazyora-windows-amd64.exe`, `lazyora-windows-arm64.exe`
- `SHA256SUMS`에 실행파일·LICENSE·README의 체크섬을 제공합니다.

로컬 Linux ARM64에서 race 테스트·vet·Docker Oracle Free 실접속 및 실제 PTY 조작을 검증했습니다. GitHub Actions가 전체 대상 빌드와 Windows AMD64 버전 명령을 검증합니다. macOS 바이너리는 이번 릴리스에 포함하지 않습니다.

## 지원 범위

- SQL 선택이 없으면 편집기 전체를 한 SQL 문장 또는 BEGIN/DECLARE 블록으로 실행하며 결과는 최대 1,000행입니다. 문장 자동 구분·SQL*Plus 스크립트·바인드 입력·DBMS_OUTPUT은 아직 미지원입니다.
- 미커밋 내역은 최근 100개의 메모리 실행 기록이며 SQL당 64 KiB를 보관합니다. 실제 행별 변경 전후 비교가 아니며 DDL·PL/SQL 내부 커밋으로 DB 상태와 차이가 있을 수 있습니다.
- Oracle DDL은 암시적 커밋을 수행할 수 있습니다. 소스 적용·컴파일 전에 확인합니다.
- CentOS 시험 완료는 사용자 확인에 근거합니다. Oracle 10g 전체 기능·SID·실Windows TUI의 상세 검증은 추가로 필요합니다.
